# 数据库分析页面设计规范

页面：数据库分析 `/database` 与五个数据集深链
参考实现：`DatabaseAnalysisWorkbench`
更新时间：2026-09-10
覆盖规则：继承科研工作台主题与抽屉规范；本页不拥有 Ketcher，也不读写共享结构。

---

## 1. 页面定位

数据库分析用于浏览全库聚合统计，并按 `全库概览 → 数据集分析 → 图表下钻 → 原始记录` 逐级查看真实数据。数据库查询负责结构精确匹配，数据库筛选负责性质阈值筛选；三者保持独立状态与路由。

- `/database` 展示四项 KPI 与五张数据集概览卡。
- `/database/process`、`/database/property`、`/database/structure-effect`、`/database/dft`、`/database/formulation` 保持可冷启动的深链。
- 数据集切换使用主表面标题区的浮层，不改变数据库分析侧栏高亮。
- 页面采用 full-bleed、满高壳层；页面标题、单一状态条和分析滚动区分层，主表面由内容决定高度，不引入共享画板所有权或离页同步。

## 2. 主题与密度

- 背景为 `#edf3f9`，普通网格为 `32px`、2K 网格为 `48px`；两档线条透明度都为 `rgba(37, 99, 235, .032)`。
- 模块身份与主装饰使用和知识检索一致的 `#1d4ed8 → #3b82f6 → #06b6d4`，重复卡片顶线降低透明度；控件及数据视图继续使用克制的蓝青主题。图表保留类别与数据语义色，不强制改成单一冷色色板。绿色只表示可用、成功或已收敛状态。
- 字体继承全局 Exo / IBM Plex Sans / Roboto Mono 体系。
- 标准工作列上限 `1040px`，基准字号 `16px`，页面标题 `20px`，表面标题 `18px`，工具按钮 `36px`，搜索输入 `44px`，表面圆角 `14px`。
- 顶部单一状态条承载统计方式、记录量、更新时间和数据源可用状态；刷新与数据集切换位于主表面标题区，层级与知识检索、聚合物生成一致。
- 主表面使用亮蓝至青色渐变顶边，KPI、数据集卡片和分析面板使用同方向的低对比版本，并配合蓝灰边框与分层阴影；字体层级保持 Exo 标题、IBM Plex Sans 正文和 Roboto Mono 数据标签。

## 3. 布局与容器断点

分析滚动区占据工具栏下方的剩余高度；主表面在其中自然增长并独立纵向滚动。所有布局断点读取 `.np-database-analysis` 的实际 inline size，而不是浏览器 viewport。

- `>1100px`：单行表头、KPI 四列、概览等宽三列，第二行两卡居中；详情双列。
- `821–1100px`：表头换行、概览两列、详情双列。
- `≤820px`：KPI 两列、详情单列。
- `≤559px`：概览及数据集选项单列，工具区换行；KPI 保持两列，矩阵和表格只在自身容器横向滚动。
- 数据集浮层在实际工作区小于 `900px` 时成为带遮罩的底部模态弹层，支持 Escape、焦点循环和关闭后的焦点恢复。

## 4. 数据与错误状态

- 初始摘要与统计快照并行读取。
- “刷新数据”先刷新统计快照，成功后同步数据源摘要；整个过程保留上次成功内容。
- 首次快照失败只重新读取快照，不触发实时重算。摘要失败不阻止有效统计内容展示，数据源状态改为未知并显示局部警告。
- 五类统计 payload 在进入视图前进行结构校验；单个数据集畸形时显示面板级错误，不影响其他数据集。
- 用户界面只展示经过本地化和安全映射的中文错误；后端原始 `message/detail` 仅用于日志，不得直出数据库表名、配置项或内部数据结构。
- 数据集返回的字段名、分类词条与状态值保持数据源原文，不在前端翻译；DFT 中的 `Step`、`SCF energy`、`Gap` 等数据术语沿用原始写法，中文仅用于标题、操作和说明文案。
- DFT PCA 请求和展示上限均为 `80`；3Dmol 脚本失败可重试，viewer 随容器尺寸变化调用 resize/render。

## 5. 原始记录抽屉

- 复用 `WorkbenchDrawerShell`。标准档并排阈值基准为根容器 `1360px`，2K 档基准为 `2050px`；抽屉超过默认宽度时阈值同步增加。不足时为模态覆盖，小于 `900px` 时为底部弹层。
- 标准宽度默认 `380px`，范围 `320–560px`，键盘步进 `16px`。
- 2K 默认 `540px`，范围 `480–720px`，键盘步进 `24px`；跨断点按旧范围中的比例映射。
- 关闭只隐藏抽屉，保留搜索、页码、响应和错误，重开不得重发请求。
- 只有下钻条件变化才重置并取消旧请求；数据集切换关闭并清理旧抽屉。
- 覆盖模式为模态并支持 Escape、焦点循环及恢复；并排模式保持非模态并显示拖拽分隔条。

## 6. 原生 2K

断点固定为 `(min-width: 2000px) and (min-height: 1120px)`。

- 工作列 `1560px`，外边距 `36px`，基准字号 `18px`，页面标题 `28px`，表面标题 `24px`。
- 工具控件 `54px`，搜索输入 `60px`，表面圆角 `20px`。
- KPI 高度约 `132px`，分析面板最小高度 `330px`。
- PCA 与三维构象区约 `285px`，Donut 约 `200px`，能量图 SVG `180px`。
- 概览继续采用等宽 `3 + 2`，详情保持双列；页面根、矩阵、表格和抽屉不得产生横向溢出。

## 7. 验收清单

- 概览、五个深链、数据集浮层、图表下钻及原始记录均可键盘操作。
- 摘要/统计单边失败、畸形快照、刷新保旧和后端错误优先级符合规范。
- 关闭重开抽屉不丢状态、不重请求；新下钻取消旧请求；数据集切换清理旧上下文。
- DFT 空样本、脚本失败重试和容器 resize 均有稳定状态。
- 2560×1440、2048×1152、1920×1080、1440×900、1366×768、1280×800、1024×768、390×844 无根级溢出、遮挡或裁切。

## 公共页头与基础主题（2026-09-10）

- 使用 `ModulePageHeader`、`.np-module-page` 和 `.np-module-page-body`，遵循 [MASTER](../MASTER.md) 的62／84／60px固定页头；标题位置和字体不由本页断点重复定义。
- 正文从页头下方开始，沿用本页工作列、滚动区、抽屉、控件密度及科学数据语义色。
- 基础颜色、边框、焦点和主表面引用公共工作台变量；本页业务规范不覆盖公共标题坐标。
