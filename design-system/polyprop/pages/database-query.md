# 数据库查询页面设计规范

页面：数据库查询 `/database-query`
参考实现：`DatabaseQueryPage`
更新时间：2026-06-26
覆盖规则：本页面继承 Master 规范，并采用聚合物相似性探索页面的居中科研工作区 + 右侧分析抽屉模式。

---

## 1. 页面定位

数据库查询是精确 SMILES lookup 工作台，用于绘制、输入或同步当前聚合物结构，并在结构-性能库、性能行表和 PI 反向设计库中检查完全匹配记录。它是科研工具页，不是数据库介绍页或全宽结果浏览页。

验收目标：

- 桌面端保留平台左侧侧栏。
- 右侧工作区使用 full-bleed 科研工作台，只保留上下 padding。
- 主结构编辑列居中，宽度明显窄于可用工作区。
- 第一屏直接提供 Ketcher 画板、图片导入、SMILES 输入、表选择和运行查询。
- 查询结果只进入右侧分析抽屉，不做成页面下方全宽内容流。

---

## 2. 布局

- AppShell 对 `/database-query` 使用与 `/explorer` 一致的 `overflow-hidden` 工作区。
- 页面根节点填满 AppShell 内容区高度。
- 居中 shell 使用冷灰背景，两侧留白只保留背景，不放工具、卡片或结果。
- 主内容列宽度与聚合物相似性探索的标准工作台一致。
- 页面标题使用紧凑 `16px`，放在工作区左上角。
- 顶部工具按钮右对齐，不能贴到浏览器最右侧。
- 分析抽屉贴工作区右边缘，默认宽度 `380px`，可拖拽范围 `320px` 到 `560px`。

---

## 3. 核心界面

### 3.1 结构工作面

- 默认正面是 2D Ketcher iframe。
- 顶部工具按钮包含 `导入图片`、`清空画布`、`生成SMILES`、`3D构象`，与聚合物相似性探索保持同款按钮样式。
- 图片导入复用结构识别接口，写入 Ketcher 后以编辑器确认的 SMILES 为准；失败时尽可能恢复原画布。
- 背面是真实 `StructurePreview3D` 查看器。
- 打开 3D 前必须先同步当前 SMILES；没有结构时不翻转，只显示局部反馈。
- 清空画布必须同步清空 SMILES、查询结果和抽屉状态。

### 3.2 SMILES 胶囊

- 默认 SMILES 为空。
- SMILES 输入区使用等宽字体，placeholder 可以包含 `*CC*`、`CCO` 示例。
- 有内容时显示复制和清空浮动按钮。
- 局部反馈保留在胶囊内部，不使用全局 toast。
- `*CC*` 等聚合物端基输入应保留，不做错误剥离。

### 3.3 表选择和运行查询

- 表选择是三段式数据源选择器：`Polymers`、`Properties`、`PI Polymer`。
- 每个选项展示表用途和匹配字段，但文案保持紧凑，不占据主画布高度。
- 运行按钮在无 SMILES 或查询中禁用，并使用 `opacity: 0.45` 表达不可用。
- 查询调用现有 `POST /api/v1/database-browser/smiles-lookup`，请求字段保持 `smiles` 和 `table`。

---

## 4. 分析抽屉

- 抽屉标题为 `查询结果`。
- 抽屉统一承载 loading、错误、无匹配和成功结果。
- Loading 使用骨架屏。
- 错误状态保留后端错误信息，并使用红色强调。
- 成功结果卡展示真实 2D 结构图、匹配 SMILES、canonical SMILES、命中字段、记录 ID 和可追溯字段。
- 抽屉关闭后显示贴边展开按钮，结果状态保留。
- 抽屉内容可以滚动，但头部和关闭按钮位置保持稳定。

---

## 5. 响应式

- 桌面宽屏是主要验收场景。
- 小于 `900px` 时，居中列占满宽度，主布局允许滚动。
- 小于 `900px` 时隐藏右侧分析抽屉和拖拽条。
- 表选择器在窄屏下改为单列，运行按钮铺满胶囊底部。
- 顶部工具按钮可以换行，但文字必须可读，不允许重叠或截断。

---

## 6. 验收清单

- `/database-query` 保留平台左侧侧栏。
- 页面第一屏直接可绘制、导入图片、输入、选择表并运行查询。
- 查询结果不出现在页面下方全宽流中。
- 结果抽屉支持 loading、错误、无匹配、成功结果和关闭后重开。
- 命中结果包含真实 2D 结构图；无结构图时有 SMILES fallback。
- 清空画布会清空 SMILES、查询状态和抽屉。
- `npm run build`、相关后端 lookup 测试和 `git diff --check` 通过。
