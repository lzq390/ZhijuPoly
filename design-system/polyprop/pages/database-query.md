# 数据库查询页面设计规范

页面：数据库查询 `/database-query`
参考实现：`DatabaseQueryPage`
更新时间：2026-09-10
覆盖规则：本页面继承 Master 规范，并完整复用结构工作台与聚合物相似性探索的共享画板、参数浮层和结果抽屉模式。

---

## 1. 页面定位

数据库查询是精确 SMILES lookup 工作台，用于绘制、输入或同步当前聚合物结构，并在结构-性能库、性能行表和 PI 反向设计库中检查完全匹配记录。它是科研工具页，不是数据库介绍页或全宽结果浏览页。

验收目标：

- 桌面端保留平台左侧侧栏。
- 右侧工作区使用 full-bleed、满高且无 AppShell 内边距的结构工作台。
- 第一屏直接提供共享 Ketcher、2D/3D、图片导入、可编辑 SMILES 与查询参数入口。
- 参数使用工作台浮层，不挤占画板的常驻高度。
- 查询结果只进入可关闭、可重开的工作台抽屉，不做成页面下方全宽内容流。

---

## 2. 布局

- AppShell 对 `/database-query` 使用与 `/explorer` 一致的 `overflow-hidden p-0` 工作区。
- 页面根节点使用 `.np-structure-workbench`，继承浅蓝灰网格背景、居中比例画板、字体与控件密度。
- 页面标题、工具栏、画板和 SMILES 区与结构工作台保持同一尺寸和对齐线。
- 抽屉默认宽度 `380px`，可拖拽范围 `320px` 到 `560px`；容器足够宽时并排，不足时覆盖。
- 2K 使用结构工作台统一的 `2000×1120` 断点，画板、字号、网格、工具栏、抽屉与结果媒体同步放大。

---

## 3. 核心界面

### 3.1 结构工作面

- 默认正面是 2D Ketcher 编辑器实例。
- 顶部工具按钮包含 `加载结构`、`导入图片`、`清空画布`、`生成SMILES`、`3D构象` 和 `查询参数`，由 `StructureCanvasSurface` 统一渲染。
- 图片导入复用结构识别接口，写入 Ketcher 后以编辑器确认的 SMILES 为准；失败时尽可能恢复原画布。
- 背面是真实 `StructurePreview3D` 查看器。
- 打开 3D 前必须先同步当前 SMILES；没有结构时不翻转，只显示局部反馈。
- 清空画布同步清空当前 SMILES；已完成的查询结果保留，并标记为对应上次提交结构。

### 3.2 SMILES 编辑区

- 默认 SMILES 为空。
- SMILES 输入区使用共享工作台的等宽可编辑文本框，输入经校验后自动同步到画板。
- 保留复制按钮和局部状态反馈，不使用全局 toast。
- `*CC*` 等聚合物端基输入应保留，不做错误剥离。

### 3.3 表选择和运行查询

- 表选择位于紧凑参数浮层，提供 `Polymers`、`Properties`、`PI Polymer` 三个单选卡。
- 每个选项展示表用途和匹配字段；桌面三列、窄屏单列，不占据主画布常驻高度。
- 提交后立即打开抽屉并显示结构同步/标准化状态；空结构不调用后端并返回参数浮层。
- 查询调用现有 `POST /api/v1/database-browser/smiles-lookup`，请求字段保持 `smiles` 和 `table`。

---

## 4. 分析抽屉

- 抽屉标题为 `数据库查询结果`。
- 抽屉统一承载 loading、错误、无匹配和成功结果。
- Loading 使用骨架屏。
- 错误状态保留后端错误信息，并使用红色强调。
- 成功结果顶部依次展示可折叠的提交结构、查询耗时、查询数据表和精确匹配状态。
- 结果卡展示真实 2D 结构图、匹配 SMILES、canonical SMILES、记录 ID 和可追溯字段。
- `Properties` 结果保留性能名称前缀筛选。
- 抽屉关闭后显示贴边展开按钮，结果状态保留。
- 结构或目标数据表改变后不清空旧结果，而是显示“对应上次提交参数”的中性提示。
- 抽屉内容可以滚动，但头部和关闭按钮位置保持稳定。

---

## 5. 响应式

- 桌面宽屏是主要验收场景。
- 响应式以模块实际容器宽度为准，不依赖 viewport 猜测侧栏后的剩余空间。
- 容器不足 `1280px` 时抽屉覆盖画板并使用遮罩、Escape、焦点循环与焦点恢复；并排模式保持非模态。
- 小于 `900px` 时参数和结果抽屉使用移动底部弹层，采用 `100dvh` 渐进增强。
- 表选择器在窄屏下改为单列，运行按钮铺满参数浮层底部。
- 所有宽度下页面、画板、参数浮层、抽屉和结果卡均不得产生横向溢出。

---

## 6. 验收清单

- `/database-query` 保留平台左侧侧栏。
- 页面第一屏直接可绘制、导入图片、编辑 SMILES，并从工具栏打开查询参数。
- 查询结果不出现在页面下方全宽流中。
- 结果抽屉支持 loading、错误、无匹配、成功结果和关闭后重开。
- 命中结果包含真实 2D 结构图；无结构图时有 SMILES fallback。
- 清空或修改结构不会误删已完成的结果，而会产生明确的快照变化提示。
- 页面离开前同步共享画板，应用任意时刻只挂载一个共享 Ketcher 编辑器实例。
- 2560×1440、1920×1080、1366×768、1024×768、390×844 下无横向溢出或裁切。
- `npm run build`、前端页面/集成/API 测试、相关后端 lookup 测试和 `git diff --check` 通过。

- 使用 `ModulePageHeader`、`.np-module-page` 和 `.np-module-page-body`，遵循 [MASTER](../MASTER.md) 的62／84／60px固定页头；标题位置和字体不由本页断点重复定义。
- 正文从页头下方开始，沿用本页工作列、滚动区、抽屉、控件密度及科学数据语义色。
- 基础颜色、边框、焦点和主表面引用公共工作台变量；本页业务规范不覆盖公共标题坐标。
