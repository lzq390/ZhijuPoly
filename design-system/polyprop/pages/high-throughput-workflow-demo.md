# 高通量优化演示工作台

## 当前重构范围

S0、S1、S2 使用统一科研工作台。S3–S6 保持既有界面和固定演示路径，不通过共享选择器扩散阶段样式。路由仍为 `/high-throughput-workflow-demo`，不新增服务、持久化或 CSV 解析。

## 视觉基线

- 主内容列 1040px，原生 2K 1560px；断点为 `(min-width: 2000px) and (min-height: 1120px)`。
- 页面 H1 和状态工具栏在滚动区外，`.ht-scroll-region` 是唯一主纵向滚动区。Surface 顶线直接使用 `np-sw-accented-surface`。
- 标题 Exo，正文 IBM Plex Sans，数值/ID/SMILES Roboto Mono。标准 H1/H2/分区标题 20/18/16px，标签/说明 12/11.5px；2K 对应 28/24/23px、15/14px。
- 推荐卡中的单体组合 ID 同样使用 Roboto Mono。图例标记随原生 2K 放大：候选/DOE/推荐点从 7px 调整为 10px，热点从 16×10px 调整为 22×14px，最优星形从 12px 调整为 16px。
- 框架及主操作蓝青色；四目标依次蓝、绿、紫、橙。标题背景为干净渐变，只有页面和科学绘图区使用网格。
- S1/S2 共用 `PriorWorkbench` 的 Agent 布局、彩色外壳、阈值框和目标页签；保留原 `ht-s1-*` 类名作为共用视觉基线。

## S2 内容顺序

Surface 标题“先验热点与推荐验证” → 七阶段导航 → 演示披露 → 场景与批次摘要 → 热点图 → 当前目标两张推荐验证卡 → 当前候选详情 → sticky 操作栏。

图表保留预设 DOE、热点和推荐点，采用原 SVG 投影。灰点表示候选，方形表示 DOE，圆点表示推荐，星形表示初始最优；热点浓淡不是预测值或置信概率。显示投影维度名称、图例以及方向感知的最优与阈值摘要。

四个 Agent 默认收起，各自一个紧贴图框的窄按钮。宽容器展开到 Surface 外，侧空不足时按已有规则覆盖图内，小容器一次只开一个。卡片只有窄按钮负责收起；外层背景和标题可选中，阈值框和分析框不触发选择。S2 卡片只展示分析与批次状态，不提供上传或样例下载。

## 验证交互与边界

- 四目标各两项，共八项；每个推荐点只输入所属目标性质。S0 演示勾选不改变这条固定门禁。
- 默认预填可编辑示例值，但未确认批次。空值和非有限数就地报错；所有值有效后先“确认本批 8 项验证值”，再“进入 S3”。
- 任意编辑取消整批确认。返回 S1 不清上传、输入或确认；任何重新导入尝试、重置先验或实际修改已确认的 S0 参数，使 S2 确认失效，但保留验证值。
- S2 重置只恢复本批默认值、清确认、选择当前目标第一条推荐，不清先验。
- 图点、推荐卡和输入选中态同步；图点选择仅在卡片不可见时滚动内部容器。结构详情进入 S2 时默认收起；切换推荐点或目标时保留展开/收起选择，只更新候选内容，由用户手动控制折叠。长 SMILES 换行。
- 推进期间锁定输入、目标切换、确认、重置和返回；已展开 Agent 仍可收起。卸载取消模拟过渡计时器。
- 输入用于演示记录和既有回流展示，不重算 S2 热点，不重训模型，不改变固定推荐或后续搜索路径。

## 可访问性与适配

目标页签支持方向键、Home、End，推荐图点支持 Enter/Space；输入不得嵌套在按钮内。状态同时有文本与图标，批次变化使用 `aria-live`，错误关联输入。阶段切换重置主滚动并聚焦 Surface 标题。

小于 700px 的内容容器采用单列推荐卡、两行底栏；小于 480px 的目标页签为 2×2。底栏 z-index 高于 Agent，2K 同步放大字号、控件和间距。尊重 `prefers-reduced-motion`。

验收覆盖 2560×1440、2048×1152、1920×1080、1440×900、1024×768、390×844：无页面横向滚动、Agent 不遮挡 CTA、长文本不溢出，S0/S1 和 S3–S6 流程回归通过。
