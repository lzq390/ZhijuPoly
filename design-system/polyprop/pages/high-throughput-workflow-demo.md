# 高通量优化演示工作台

## 当前重构范围

S0–S4 使用统一科研工作台。S5–S6 保持既有界面和固定演示路径，不通过共享选择器扩散阶段样式。路由仍为 `/high-throughput-workflow-demo`，不新增服务、持久化或 CSV 解析。

## 视觉基线

- 主内容列 1040px，原生 2K 1560px；断点为 `(min-width: 2000px) and (min-height: 1120px)`。
- 页面 H1 和状态工具栏在滚动区外，`.ht-scroll-region` 是唯一主纵向滚动区。Surface 顶线直接使用 `np-sw-accented-surface`。
- 标题 Exo，正文 IBM Plex Sans，数值/ID/SMILES Roboto Mono。标准 H1/H2/分区标题 20/18/16px，标签/说明 12/11.5px；2K 对应 28/24/23px、15/14px。
- Agent 与轮次卡标题共用卡片标题字号 13px / 17px（标准 / 原生 2K），Exo、700；不再用标签字号加偏移值。目标切换、上传、样例与结构展开使用控件字号 12px / 15px，辅助状态和图例仍为 11.5px / 14px。窄屏保留 18px 的 Surface 标题，不缩到分区标题以下。
- 证据摘要只将数量包为 Roboto Mono，中文和 DOE 说明使用正文；收敛对照的 p1–p4 标识显式使用 Roboto Mono、600，避免嵌套加粗产生 900 字重。
- 推荐卡中的单体组合 ID 同样使用 Roboto Mono。图例标记随原生 2K 放大：候选/DOE/推荐点从 7px 调整为 10px，热点从 16×10px 调整为 22×14px，最优星形从 12px 调整为 16px。
- 框架及主操作蓝青色；四目标依次蓝、绿、紫、橙。标题背景为干净渐变，只有页面和科学绘图区使用网格。
- S0 是 S0–S4 的浅色视觉基线：Surface、主标题和 S0–S6 导航直接共用同一规则，不增加阶段专属蓝底或蓝色选中大块。内容区白底，分区共用浅灰蓝背景、细边框及深灰蓝标题；目标页签采用与 S0 相同的浅色选中底和细底线。候选空间保留 2px 明确边框，改为中性灰蓝；Agent 仍保留各自目标色，主按钮保留蓝色强调。
- 候选空间在浅色基底上单独体现仪表面板层次：中性灰蓝双层边框、细内缩高光、轻阴影及分段目标切换底座；选中目标用浅色浮起面和目标色底线区分，不使用深色填充。绘图区增加固定尺寸角标和与原 SVG 坐标对齐的低对比细网格，装饰不截获点击、不参与读屏，也不改变点位、热点或原有图例语义。2K 同步放大底座间距和角标；不加扫描、闪烁或假运行状态。此精修只作用于 S1–S3 候选空间，不改变已确认的 Surface 标题和阶段导航。
- S1–S3 共用 `PriorWorkbench` 的 Agent 布局、彩色外壳、阈值框和目标页签；保留原 `ht-s1-*` 类名作为共用视觉基线。S2/S3 的推荐卡与结构详情由 `RecommendationValidation` 共享，样式仅作用于工作台验证区。
- 主输入及底栏按钮标准 38px、原生 2K 50px。S3 回流记录和阈值保留用户输入的小数精度，避免显示舍入值与达标状态不符。

## S2 内容顺序

Surface 标题“先验热点与推荐验证” → 七阶段导航 → 演示披露 → 场景与批次摘要 → 热点图 → 当前目标两张推荐验证卡 → 当前候选详情 → sticky 操作栏。

图表保留预设 DOE、热点和推荐点，采用原 SVG 投影。灰点表示候选，方形表示 DOE，圆点表示推荐，星形表示初始最优；热点浓淡不是预测值或置信概率。显示投影维度名称、图例以及方向感知的最优与阈值摘要。

四个 Agent 默认收起，各自一个紧贴图框的窄按钮。宽容器展开到 Surface 外，侧空不足时按已有规则覆盖图内，小容器一次只开一个。卡片只有窄按钮负责收起；外层背景和标题可选中，阈值框和分析框不触发选择。S2 卡片只展示分析与批次状态，不提供上传或样例下载。

## 验证交互与边界

- 四目标各两项，共八项；每个推荐点只输入所属目标性质。S0 演示勾选不改变这条固定门禁。
- 默认预填可编辑示例值，但未确认批次。空值和非有限数就地报错；所有值有效后先“确认本批 8 项验证值”，再“进入 S3”。
- 任意编辑取消整批确认。返回 S1 不清上传、输入或确认；任何重新导入尝试、重置先验或实际修改已确认的 S0 参数，使 S2 确认失效，但保留验证值。
- S2 重置只恢复本批默认值、清确认、选择当前目标第一条推荐，不清先验。
- 图点、推荐卡和输入选中态同步；图点选择仅在卡片不可见时滚动内部容器。结构详情进入 S2 时默认收起；切换推荐点或目标时保留展开/收起选择，只更新候选内容，由用户手动控制折叠。长 SMILES 换行。
- 推进期间锁定输入、目标切换、确认、重置和返回；已展开 Agent 仍可收起。卸载取消模拟过渡计时器。
- 输入用于演示记录和既有回流展示，不重算 S2 热点，不重训模型，不改变固定推荐或后续搜索路径。

## 可访问性与适配

目标页签支持方向键、Home、End，推荐图点支持 Enter/Space；输入不得嵌套在按钮内。状态同时有文本与图标，批次变化使用 `aria-live`，错误关联输入。阶段切换重置主滚动并聚焦 Surface 标题。

小于 700px 的内容容器采用单列推荐卡、两行底栏；小于 480px 的目标页签为 2×2。底栏 z-index 高于 Agent，2K 同步放大字号、控件和间距；Agent 保持 264px 宽，上传操作间距 6px、样例按钮水平内边距 4px，保证 15px 的“重新上传 CSV”完整显示。尊重 `prefers-reduced-motion`。

验收覆盖 2560×1440、2048×1152、1920×1080、1440×900、1024×768、390×844：无页面横向滚动、Agent 不遮挡 CTA、长文本不溢出，S0–S2 和 S3–S6 完整演示路径保持回归覆盖。

## S3 内容顺序与数据口径

Surface 标题“单性质迭代与验证回流” → 七阶段导航 → 演示披露 → 场景摘要 → R1/R2/收敛轮次导航 → 候选空间大图 → 推荐验证或收敛对照 → sticky 操作栏。常驻披露：

> 当前按预设路径演示单性质迭代。验证值参与回流记录及已回流样本最优比较，不重训模型，不改变预设热点、推荐顺序和后续配方路径。

| 查看轮次 | 图中已回流记录（每目标） | 本批验证 | 每目标证据 |
|---|---|---|---|
| R1 | S2 的 2 点 | 每目标 2 项，共 8 项 | DOE 12 + 回流 2 |
| R2 | S2 与 R1 的 4 点 | 每目标 1 项，共 4 项 | DOE 12 + 回流 4 |
| 收敛 | 前述记录和最终 1 点 | 无输入、无确认按钮 | DOE 12 + 回流 5 |

- R1 不重复 S2 已验证批次。推荐 ID、热点快照、脚本解释与输出 p1–p4 直接使用现有场景数据，不受验证值更改影响。
- `iteration-model` 根据查看轮次派生证据前缀，按 DOE → S2 → R1 → R2 的顺序比较最优；CTE 取小，其余取大，并列保留先出现记录。未回流的本批及未来预填值不参与。
- 图中星标、图下“回流记录最优”、Agent 和收敛对照共用一个派生结果；“预设路径候选”单独展示，不再混用“当前最优”。验证值仍以“目标:候选 ID”为键，隔离不同目标的 PI-734。
- 图形沿用既有 SVG 与投影/热点算法；灰点为候选、空心方框为 DOE、实心圆为已回流、空心圆为本轮验证、星形为记录最优。图点补充 ID、来源、状态，热点明确是预设区域示意。
- Agent 默认全部收起，四个窄按钮独立；外层可选择目标，阈值和分析内框不触发选择。卡内增加轮次、证据计数、两类候选及“预设决策”，不提供上传。外侧展开卡的高度限制在各自轨道范围，避免较长脚本说明导致上下卡重叠；侧空不足时以内侧锚点避让，同侧最多一张，小容器全局最多一张。

## S3 操作与上游衔接

- 轮次导航中 R1/R2 使用编号标识；收敛使用无边框的对照图标，并将中文名称并入“收敛对照”标题，不在编号方框内排中文。图标仅作装饰，保留“收敛 当前/未开始”的可访问名称、键盘切换和原有进度门禁。
- 独立保存进度轮次与查看轮次；只有推进修改进度。已完成轮次只读回看，未来轮次禁用。回看图不叠加后续回流，验证值变为只读文本，隐藏工具栏重置，底栏仅“返回当前轮次”。
- R1/R2 预填有效不等于确认；先确认本批 8/4 项，再进入 R2/收敛。空值/非有限数就地报错并汇总缺项目标。编辑任一当前批数值取消该批确认，确认本身不把本批加入证据。
- R1 两张卡并列；R2 单卡占满一行，桌面内部按候选摘要/验证输入分两区，小容器纵向排列。收敛改为“回流记录最优”与“预设输出候选 pX”两张可选对照卡，无新增输入，直接进入 S4。
- 结构详情首次进入 S3 默认收起，切换候选、目标、轮次及收敛对照均保留展开状态；离开 S3 后重新进入则收起。图点、卡片、输入双向选中，输入不被抢焦点；只在必要时滚动内部工作区定位验证卡。
- S3 滚动区通过底栏实际高度设置滚动预留空间，焦点/自动定位的控件不得落在 sticky 底栏下；离开 S3 清除此阶段的高度变量。
- 当前轮可返回 S2，保留 S3 输入、确认、进度；未更改上游时再进入，恢复进度轮次，不恢复历史回看位置。
- S2 修改或重置、S1 导入尝试（包括失败）或重置、S0 实际参数变化或重置，撤销 S3 两轮确认并将进度/查看轮次归零，但保留 S3 已填值。仅返回、切换目标或重新确认未变的 S0 不失效。
- 当前批重置只恢复本批默认值、撤销其确认，并选中当前目标首个推荐点。收敛“重演 S3”使用原生二次确认，确认后恢复 S3 两批共 12 项默认值、清确认、返回 R1，保留 S0–S2 和当前目标；取消不更改任何状态。
- 推进期间禁止编辑、轮次/目标切换、返回、重置和重复确认；仍可收起已展开 Agent。过渡文案为“正在演示验证回流”，不声称训练模型。

## S4 内容与交接

Surface 标题“单性质候选输出” → 七阶段导航 → 固定演示披露 → 场景摘要 → 四个预设输出组分 → 候选性质与来源（辅助位置图和备选）→ 结构详情 → sticky 操作栏。

- 四张 p1–p4 摘要承接四个 Agent 的输出，取代本阶段旧环绕卡片、大图和顶部推进条；直接复用 `TargetTabs` 的选中与键盘逻辑。卡片只选择查看目标，不能替换组分。显示 ID、组分用途、预测/模拟值和带图标的达标状态。
- `candidate-output-model` 从 `formulation.components` 读取固定输出，备选沿用各 Agent 的 Top-k 顺序并排除输出本身。S3 已确认的验证值只进入单独的“回流记录最优”来源对照，不改 p1–p4、备选排序或 S5 配方池。
- 当前候选显示四性质预测/模拟值、S0 已确认阈值、正确优化方向和达标状态；小数阈值不舍入，温度使用 °C。性质尚未全部达标不阻断预设配比演示，不增加确认或输入门禁。
- 结构类别、单体组合、完整三类 SMILES 复用现有场景与结构详情组件，不增加结构解析服务。结构展开状态在 S4 内跨组分/备选保留；每目标保留最近查看的备选。离开 S4 再进入时恢复默认输出预览和折叠状态。
- 小型位置图继续使用原 SVG、投影算法和预设收敛热点。灰点为候选、星形为固定输出、空心方块为备选、虚线圆表示当前查看；不显示 DOE/回流批次点，避免与输出状态混淆。图点支持鼠标、Enter/Space，与候选列表双向联动；必要时只定位内部详情区，不滚动页面。图例明确投影位置不是性能排名，热点不代表实时预测。
- 底栏提供“返回 S3 收敛对照”和“进入 S5 多目标配比搜索”。返回保留 S3 进度、值和确认，进入 S5 始终传递原预设组分。本阶段没有待编辑批次，不显示无实际作用的重置按钮。推进期间锁定目标、候选、结构展开、返回和重复推进，并播报过渡状态。
- 窄屏阶段条进入时自动水平定位到 S4；不滚动文档或抢焦点，离开 S4 恢复之前的阶段条位置。保留唯一主纵向滚动区域。
- 延用 1040px / 1560px 工作面与原生 2K 断点；标题层级、13/17px 卡片标题、12/15px 控件、11.5/14px 辅助文字保持统一。数值强调 20/26px，主按钮 38/50px，不使用旧 850–950 字重。
- 详情标准桌面采用主信息 + 330px 位置区，2K 为主信息 + 420px 位置区；上方四性质保持 2×2，与位置区形成平衡的双栏。双栏等高，性质卡片自适应吸收高度差，让来源框与位置区底边齐平，到下方结构详情的间距保持一致；不增加额外占位或固定高度。结构详情独立占下方整行，展开不再只拉长左列；Polymer SMILES 占整行，单体 A/B 在下一行并列，长文本局部换行。内容容器小于 900px 时主信息/位置区上下布局，小于 700px 时输出卡 2×2、三类 SMILES 单列，小于 480px 时四性质及位置区单列。图点和备选列表在详情不可见时都只定位内部详情区。底栏按容器宽度分行，通过实测高度为内部滚动预留空间。
