# 均聚物性质预测页面设计规范

页面：均聚物性质预测 `/homopolymer-property-prediction`
参考实现：`HomopolymerPropertyPredictionPage`
更新时间：2026-09-10
覆盖规则：复用结构工作台的满高画板、工具栏、参数浮层和结果抽屉。

---

## 1. 页面定位

均聚物性质预测用于对单一结构运行九项模型预测。页面接受普通 SMILES 和带 `*` 连接点的重复单元，不额外限制连接点数量；后端继续使用现有 `POST /api/v1/predict` 契约。

九项性质只维护一份公共前端目录，并按固定顺序分为：

- 热学：Tg、Tm、Td、热分解失重率。
- 力学：断裂伸长率、断裂拉伸强度。
- 气体渗透：O₂、CO₂、H₂ 渗透率。

## 2. 结构画板

- 完整复用结构工作台的 Ketcher、2D/3D、图片导入、SMILES 同步、复制和清空能力。
- 默认画板为空，“加载结构”写入示例 `*CC*`。
- 页面只显示“预测参数”工具入口；离页前同步共享结构。
- 应用任意时刻只挂载一个共享 Ketcher 编辑器实例。

## 3. 参数与提交

- 首次进入默认全选九项；支持分组选择、全选和清空。
- 参数浮层沿用结构工作台表面语言，以“分组标签列 + 紧凑性质选项行”展示，避免少量参数占用大面积画板。
- 标准桌面使用 `17px` 浮层标题、`13px` 分组标题、`12px` 性质名称和 `10.5px` 缩写/单位；2K 对应提升为 `24/17/16/13px`，不使用低于 `10.5px` 的关键信息文字。
- 未选择性质时禁用提交，不隐式回退到 Tg。
- 提交前从画板同步并标准化 SMILES，只拦截空结构。
- 请求性质始终按公共目录的固定顺序发送。
- 新请求取消旧请求；取消、卸载或过期响应不得覆盖当前页面状态。

## 4. 结果抽屉

- 只有发生过预测后才显示抽屉或重开入口；提交后立即打开。
- 关闭抽屉不清除结果；右侧中部显示与聚合物生成一致的独立展开把手，可直接恢复上次结果而不重新预测。移动端把手位于右下角。
- 依次覆盖 loading、成功、部分返回和失败状态。
- 结果展示中文名、缩写、值、单位和总查询耗时；缺失项显示“未返回”，不得填充为 `0`。
- 保存提交时的 SMILES 与性质快照。结构或选择变化后保留结果，并标记“当前结构或性质选择已变化”。
- 不展示装饰性伪量表、未经模型支持的置信区间或科学量程。

## 5. 响应式与 2K

- 使用结构工作台的实际容器宽度决定并排抽屉、覆盖抽屉和移动底部弹层。
- 默认抽屉宽度 `380px`，拖拽范围 `320px` 至 `560px`，键盘步进 `16px`。
- 移动弹层使用 `100vh` 回退和 `100dvh` 渐进增强；覆盖模式具有模态语义、焦点循环、Escape 关闭与焦点恢复。
- `(min-width: 2000px) and (min-height: 1120px)` 下同步采用结构工作台的原生 2K 字号、间距、画板和抽屉放大规则。

## 6. 验收清单

- 新路由可冷启动深链，并位于侧栏“材料设计”首项。
- 九项默认全选，分组、全选、清空和固定顺序请求正确。
- 普通 SMILES 与带 `*` 的重复单元均可提交。
- 部分响应明确显示缺失项，参数变化不会清除旧结果。
- 连续请求、卸载和离页不会产生过期状态回写或画板内容丢失。
- 2D/3D、图片导入、移动抽屉、2K 布局及单编辑器实例 所有权无回归。
- `/explorer` 不再显示性质预测入口。

## 结构信息条（2026-11-23）

- 画板 SMILES 栏下方一行显示 RDKit 结构信息：分子式、分子量、重原子、芳香环、可旋转键、TPSA、连接点。数据来自 `POST /api/v1/structure/descriptors`（结构类、只限频），结构稳定约 350 ms 后请求，同一 SMILES 在本页缓存。
- 连接点 `*` 不计入分子式和原子数；分子量是重复单元的质量。
- 每一项在悬停、键盘聚焦或点按时显示一句说明；“说明”打开使用说明里的“结构信息”段落。说明只写常见趋势，并注明这些不是模型预测值。
- 连接点为 1 个或 3 个以上时该项显示为提醒色，但不阻止提交；没有连接点按普通 SMILES 处理。
- 未登录、免费账号或没有结构时不显示，也不触发登录提示；计算中保留上次数值并降低不透明度；无法解析或服务失败时显示一行说明。
- 结构区宽度不足 760px 时收起行标题，说明改为横跨整条；不足 560px（手机）改为带标题的四列网格。

## 视觉层：精密仪器读数（2026-11-23）

布局不变（左结构、右任务、辅助栏），只重做视觉层。出发点是这个模块的工作方式：画一个重复单元，读九个物性读数，改结构再比。页面应像一台调校好的测量仪器：左边是绘图纸，右边是带刻度的读数。“科技感”来自精确（刻度、对齐的数字、同一套标记语言），“高级感”来自克制（一种墨色、一种操作色、三种通道色），不用深色霓虹、渐变装饰或卡片堆叠。

**颜色**

| 名称 | 值 | 用途 |
| --- | --- | --- |
| 墨 | `#13203A` | 标题、读数、选中文字 |
| 次墨 | `#3A4760` | 正文 |
| 灰 | `#6B7689` | 单位、说明、次要信息（白底对比度 ≥ 4.5） |
| 刻线 | `#E4E8EF` / 控件边 `#D2D9E3` / 刻度 `#C3CCD8` | 分隔、控件、刻度线 |
| 页底 / 绘图纸 | `#F3F5F8` / `#FBFCFD` | 页面背景、画板底色 |
| 钴蓝 | 平台 `--np-theme-blue` | 唯一的操作色：主按钮、焦点、当前运行 |
| 通道色 | 热学 `#C65A24`、力学 `#0E8073`、气体渗透 `#6A4FD0` | 只用于性质分组：选择标签、读数标记、分组标题 |

**字体**：沿用平台的 IBM Plex Sans 与中文回退字体；读数用等宽数字（`tabular-nums`）对齐；SMILES 用等宽字体，因为它是代码。不用全大写标签、不在标题上方加小字眉标、不用“·”拼接元信息。

**标志性元素：读数刻度条**。结果表每行在名称和数值之间有一条细刻度条：实心点是本次读数，空心圈是对比运行，两点之间用通道色细线连接；结果更新时标记滑到新位置（减少动态效果时不动画）。刻度是固定的显示区间，不代表数据库分布：Tg −150–450 °C、Tm 0–500 °C、Td 200–700 °C、失重率 0–100 %、拉伸强度 0–200 MPa，断裂伸长率 1–1000 % 和三种渗透率 0.01–10⁴ Barrer 用对数刻度；超出区间的读数停在端点并显示箭头。悬停一行时在刻度两端显示区间。

**其他区域**

- 画板：绘图纸底色加 22px 点阵；Ketcher 浮动工具栏改为细描边加浅阴影，和页面表面一致。
- SMILES 栏与结构信息条：等宽 SMILES；同步状态前加状态点；结构信息像仪器铭牌，项与项之间用细竖线分隔。
- 预测内容：选择标签按通道着色；收起时用一条九格的选择条显示哪些性质被选中。
- 运行按钮：钴蓝实心，右侧显示快捷键；运行中底部有一条进度线。
- 对比：下拉框旁边用同一套实心点/空心圈说明“本次”和“对比”；会话运行列表也用这套标记。
- 用这个结构继续：带图标的小按钮。

## 公共页头与基础主题（2026-09-10）

- 使用 `ModulePageHeader`、`.np-module-page` 和 `.np-module-page-body`，遵循 [MASTER](../MASTER.md) 的62／84／60px固定页头；标题位置和字体不由本页断点重复定义。
- 正文从页头下方开始，沿用本页工作列、滚动区、抽屉、控件密度及科学数据语义色。
- 基础颜色、边框、焦点和主表面引用公共工作台变量；本页业务规范不覆盖公共标题坐标。
