# 均聚物性质预测页面设计规范

页面：均聚物性质预测 `/homopolymer-property-prediction`
参考实现：`HomopolymerPropertyPredictionPage`
更新时间：2026-11-24
覆盖规则：复用结构工作台的满高画板、工具栏、参数浮层和结果抽屉。

---

## 1. 页面定位

均聚物性质预测用于对单一结构运行九项模型预测。页面接受普通 SMILES 和带 `*` 连接点的重复单元，不额外限制连接点数量；后端继续使用现有 `POST /api/v1/predict` 契约。

九项性质只维护一份公共前端目录，并按固定顺序分为：

- 热学：Tg、Tm、Td、热分解失重率。
- 力学：断裂伸长率、断裂拉伸强度。
- 气体渗透：O₂、CO₂、H₂ 渗透率。

## 2. 结构画板

- 完整复用结构工作台的 Ketcher、2D/3D、图片导入、SMILES 同步、复制和清空能力。
- 默认画板为空，“加载结构”写入示例 `*CC*`。
- 页面只显示“预测参数”工具入口；离页前同步共享结构。
- 应用任意时刻只挂载一个共享 Ketcher 编辑器实例。

## 3. 参数与提交

- 首次进入默认全选九项；支持分组选择、全选和清空。
- 参数浮层沿用结构工作台表面语言，以“分组标签列 + 紧凑性质选项行”展示，避免少量参数占用大面积画板。
- 标准桌面使用 `17px` 浮层标题、`13px` 分组标题、`12px` 性质名称和 `10.5px` 缩写/单位；2K 对应提升为 `24/17/16/13px`，不使用低于 `10.5px` 的关键信息文字。
- 未选择性质时禁用提交，不隐式回退到 Tg。
- 提交前从画板同步并标准化 SMILES，只拦截空结构。
- 请求性质始终按公共目录的固定顺序发送。
- 新请求取消旧请求；取消、卸载或过期响应不得覆盖当前页面状态。

## 4. 结果抽屉

- 只有发生过预测后才显示抽屉或重开入口；提交后立即打开。
- 关闭抽屉不清除结果；右侧中部显示与聚合物生成一致的独立展开把手，可直接恢复上次结果而不重新预测。移动端把手位于右下角。
- 依次覆盖 loading、成功、部分返回和失败状态。
- 结果展示中文名、缩写、值、单位和总查询耗时；缺失项显示“未返回”，不得填充为 `0`。
- 保存提交时的 SMILES 与性质快照。结构或选择变化后保留结果，并标记“当前结构或性质选择已变化”。
- 不展示装饰性伪量表、未经模型支持的置信区间或科学量程。

## 5. 响应式与 2K

- 使用结构工作台的实际容器宽度决定并排抽屉、覆盖抽屉和移动底部弹层。
- 默认抽屉宽度 `380px`，拖拽范围 `320px` 至 `560px`，键盘步进 `16px`。
- 移动弹层使用 `100vh` 回退和 `100dvh` 渐进增强；覆盖模式具有模态语义、焦点循环、Escape 关闭与焦点恢复。
- `(min-width: 2000px) and (min-height: 1120px)` 下同步采用结构工作台的原生 2K 字号、间距、画板和抽屉放大规则。

## 6. 验收清单

- 新路由可冷启动深链，并位于侧栏“材料设计”首项。
- 九项默认全选，分组、全选、清空和固定顺序请求正确。
- 普通 SMILES 与带 `*` 的重复单元均可提交。
- 部分响应明确显示缺失项，参数变化不会清除旧结果。
- 连续请求、卸载和离页不会产生过期状态回写或画板内容丢失。
- 2D/3D、图片导入、移动抽屉、2K 布局及单编辑器实例 所有权无回归。
- `/explorer` 不再显示性质预测入口。

## 结构信息条（2026-11-23）

- 画板 SMILES 栏下方一行显示 RDKit 结构信息：分子式、分子量、重原子、芳香环、可旋转键、TPSA、连接点。数据来自 `POST /api/v1/structure/descriptors`（结构类、只限频），结构稳定约 350 ms 后请求，同一 SMILES 在本页缓存。
- 连接点 `*` 不计入分子式和原子数；分子量是重复单元的质量。分子式（元素与下标）是一段连续文字，数值行的 3px 间距只用在分子式和单位之间，不把 C₅H₈O₂ 拆成“C 5 H 8 O 2”。
- 每一项在悬停、键盘聚焦或点按时显示一句说明；“说明”打开使用说明里的“结构信息”段落。说明只写常见趋势，并注明这些不是模型预测值。
- 连接点为 1 个或 3 个以上时该项显示为提醒色，但不阻止提交；没有连接点按普通 SMILES 处理。
- 未登录、免费账号或没有结构时不显示，也不触发登录提示；计算中保留上次数值并降低不透明度；无法解析或服务失败时显示一行说明。
- 结构区宽度不足 760px 时收起行标题，说明改为横跨整条；不足 560px（手机）改为带标题的四列网格。
- 本页隐藏 Ketcher 左侧工具栏的反应工具组（反应加号、箭头、原子映射）和注释工具组（形状、文字、图片）：本页只预测单一重复单元，这些内容不进入 SMILES，也不参与预测。左侧工具栏所需高度由约 594px 降到约 382px。
- 高度不超过 800px 时，画板上方工具栏、SMILES 栏、信息条的上下内边距和页面底边距共收紧约 26px。信息条加入后，Ketcher 左右两侧工具栏在 1366×768 及更大窗口中都完整显示；1280×720 下左侧完整，右侧原子栏（约需 450px）仍差约 34px，保留 Ketcher 自带的滚动箭头。

## 视觉系统：精密白（2026-11-23）

布局不变（左结构、右任务、辅助栏）。这一版把视觉层按“基础 → 组件 → 区域”系统重建：页面像一台调校好的浅色测量仪器，左边是嵌在表面里的绘图纸，右边是浅灰底上的两张卡片（输入、输出）。“科技感”来自精确（刻度、对齐的数字、同一套标记），“高级感”来自克制（一种墨色、一种操作色、三种通道色），不用深色霓虹、渐变装饰或成排相同的卡片。另一个方向“深色仪表台”做过效果图，未采用。

### 组件

- **区块标题**：浅蓝底图标块 + 16px 标题 + 状态徽标 + 右侧操作。结构（六边形）、预测内容（清单）、预测结果（仪表）、会话记录（历史）四处统一。
- **按钮**：主按钮（钴蓝实心 48px，右侧显示 Ctrl/⌘ + ↵ 快捷键，运行中底边有进度线）；次按钮（白底细边浮起）；幽灵按钮（无边，悬停凹槽色）；画板工具按钮同为幽灵按钮。“清空画布”平时和其他工具一样是灰色，悬停时变红（浅红底、红色图标），在要点下去的那一刻提示这是破坏性操作；静止时不用红色，避免它成为工具条上最醒目的按钮，也避免和结果里表示“降低”的红色混淆。
- **分段切换**：2D | 3D，凹槽轨道里当前项浮起。
- **示例菜单**：“示例”打开带结构缩略图的菜单（PE、PS、PMMA、PI），方向键选择、Esc 关闭。
- **对比选择**：外观显示对比运行的空心圈、第几次、时间、SMILES 和 Tg；打开后是与“示例”“导出”同一种浮层菜单（见下节），每次运行一个单选项。
- **性质选择**：宽面板为两列开关卡片（名称 + 单位；选中时仍为白底、边框加深一级，通道色只留在实心勾选框和分组图标上，九张卡片不再比运行按钮和结果更抢眼）；展开时不再重复“热学 4 项…”一行（徽标给总数、各组标题给组内计数），这一行只在收起且部分选择时列出所选缩写，未选任何性质时说明为什么不能运行；窄面板（≤ 440px）改为自动换行的标签；收起时为按通道分组的选择条加分组标注。
- **SMILES 输入**：凹槽代码框，左侧 “SMILES” 标签，右侧同步指示灯和复制；窄结构区只留指示灯。默认一行高（48px），长 SMILES 随内容增高到约三行后在框内滚动（`field-sizing: content`）；不支持该属性的浏览器保持公共组件的两行。
- **徽标与指示灯**：圆角徽标（中性 / 强调）；同步指示灯 绿 = 已同步、黄 = 同步中、红 = 出错。

### 区域

- **结构区**：绘图纸内嵌在表面中（12px 圆角、细边），22px 点阵，四角定位标记；Ketcher 浮动工具栏用细边和柔和阴影。Ketcher 默认把工具画成 #333，比本页任何墨色都重，所以本页改为：工具图标用灰 `#5F6B80`（与上方结构工具条的图标一致），原子符号用次墨 `#3A4760`，悬停和选中的工具（含选中的原子）用钴蓝，替代 Ketcher 的青色。本页隐藏 Ketcher 顶栏的 Open、Save as、Help：页面工具条已有“示例／我的结构”“保存结构”“使用说明”，而这三个按钮会在下一行用同样的文件夹、软盘、问号图标做不同的事（文件对话框、下载文件、英文帮助）。手机宽度（工作台 < 560px）Ketcher 顶栏本就超出画板约 60px，缩放选择器连同它前面的竖线一并隐藏，避免只露出半个“1”。
- **右侧面板**：浅灰底上两张卡片：输入卡（预测内容 + 运行）和结果卡（结果表 + 会话记录，内部滚动，滚动后输入卡加阴影）；底部“用这个结构继续”为白色通栏。还没有这条通栏时（尚未运行），面板底部留 12px（2K 为 16px），结果卡不贴住表面底边；左侧没有结构信息条时（空画板），SMILES 栏下方同样留 12px。
- **读数刻度条**（沿用）：结果表每行在名称和数值之间有一条细刻度条，实心点是本次，空心圈是对比运行，之间用通道色细线连接；刻度是固定显示区间（Tg −150–450 °C、Tm 0–500 °C、Td 200–700 °C、失重率 0–100 %、拉伸强度 0–200 MPa；断裂伸长率 1–1000 % 与三种渗透率 0.01–10⁴ Barrer 为对数刻度），不代表数据库分布；超出区间停在端点并带箭头；悬停一行显示区间两端。
- **空画板**：引导标题 + 四个示例卡（宽结构区一行四个、结构图在上）。引导层（`StructureEditor` 的 `overlay`）放在编辑器自身的隔离层叠上下文里：盖在 Ketcher 画布和工具栏之上，低于 Ketcher 的工具栏展开（z 20）和菜单（z 1300）。所以缩放菜单、键型展开等在窄布局下也不会被示例卡挡住，点到的是菜单项而不是示例卡。
- **矮画板的空画板**：引导层是尺寸容器（`np-hp-guide`），高度不超过 400px 时去掉结构图，只留名称卡。宽度不小于 560px 时四张卡排成一行；更窄时去掉说明句。这样引导内容落在 Ketcher 顶部工具栏和底部模板栏之间。
- **窄布局画板高度**：工作台宽度不足 900px 时画板高 300px，`--np-hp-canvas-min` 与 `--np-hp-pad` 设在工作台的子元素上，因为容器查询不匹配容器本身。Ketcher 原生外层自带行内 360px 最小高度，本页通过 `--np-structure-editor-min` 让它跟随画板高度，所以 300px 画板里底部模板栏完整可见，不再被裁掉。

### 尺寸与触屏

- 页面左右和底部留白与页头标题内缩一致：20px（2K 36px，≤ 1199px 16px），工作面左缘对齐标题、右缘对齐页头工具条。
- ≥ 1800px 面板 600px；1366–1399 为 372px；≤ 1279 为 340px；面板 ≤ 440px 时对比状态隐藏刻度条和图例、性质改为标签。
- 手机：结构标题单独一行，工具占第二行；触屏上所有控件 ≥ 44px。
- 2K（≥ 2000×1120）：字号、控件、圆角、间距按约 1.3 倍放大。

## 视觉系统迭代：浮层、对比着色、页头与说明（2026-11-24）

### 页头

- 标题几何、字体、颜色仍按 MASTER（20px／2K 28px，750，`#0B1F3A`，坐标不变）。标题右侧可选一行说明（`ModulePageHeader` 的 `meta`）：细竖线 + 13px 灰字“从重复单元结构预测热学、力学与气体渗透性质，共 9 项”；宽度 < 1200px 时隐藏。说明是标题的兄弟元素，不进入 `h1`。
- 页头工具（`ModuleTools`，本页与 Tg 逆向设计共用）合为一个白色胶囊：1px 细边、3px 内边距、组间细竖线（工具 │ 记录 │ 使用说明）。按钮是 30px 幽灵按钮（2K 42px），悬停凹槽色，按下为浅蓝底蓝字；AI 助手的图标固定用操作蓝，但未开放时（`ModuleTool.status`）图标改回灰色，标签后加浅灰小标签“未开放”（11px／2K 13px），读屏名称为“AI 助手，未开放”；按钮仍可打开辅助栏。AI 浏览总结入口在胶囊内去掉渐变和边框，高度仍为 30px／2K 42px；本模块未接入时为灰字禁用，悬停说明原因；空闲时图标为录制圆点（CircleDot），不再与 AI 助手共用星形图标；记录中为绿字浅绿底。手机上胶囊外观取消，只保留 44px 图标按钮。

### 浮层菜单（示例、导出、对比）

- 一套行为（`usePopoverMenu`）：点击或 ↓／↑ 打开，焦点落在已选项或第一项；↑↓、Home、End 移动，Enter 选择；Esc 关闭并把焦点还给触发按钮；点外部或 Tab 离开时关闭。菜单项 `tabIndex=-1`。
- 一种表面：白底、12px 圆角、细边 + 柔和长阴影、6px 内边距，120ms 淡入（减少动态效果时关闭）；最大高度取 440px 与触发按钮下方剩余空间中的较小值，超出时菜单内部滚动。
- 一种菜单项：前导（图标块、结构缩略图或运行圈）+ 标题（13px 600）与一行灰字 + 尾部数值 + 已选对勾；悬停／聚焦为凹槽色，已选为浅蓝底。
- 触发按钮打开时有蓝色外圈，箭头翻转。
- 导出菜单两项带图标和用途说明（下载 CSV：模型原始数值，对比时含对比列；复制表格：可直接粘贴到 Excel 等表格软件）；结果以小药丸提示（成功绿、失败红），约 2.4 秒消失。
- 对比菜单：“不对比”（虚线圈）+ 分隔线 + 其余运行（第 N 次运行、时间、SMILES、Tg），已选项打勾。
- Ketcher 自带的两个下拉也套用同一套外观（本页限定）：缩放（200%）和 Molecules 模式切换的触发按钮改为 28px 幽灵按钮 + 14px 灰色箭头，打开时蓝圈、箭头翻转；两个标签固定 13px，2K 下跟随 Ketcher 工具栏不放大；窄工具栏 Ketcher 只显示图标时，按钮保持小方块、图标 18px。菜单表面、菜单项、悬停和已选样式与上面一致；缩放数值框为凹槽输入框，快捷键以键帽显示；当前模式为浅蓝底 + 蓝色对勾。模式菜单被 Ketcher 挂到 `body` 下，用“本页持有画板”限定作用域，其他页面的 Ketcher 不受影响。菜单文字（Zoom in 等）仍是 Ketcher 的英文界面。
- 菜单打开时画布四角的定位标记隐藏，不压在菜单上。

### 结果

- 结果卡分为固定头部（标题、第 N 次运行、耗时、导出、对比选择和图例）和滚动主体（提示、结果表、会话记录）；主体滚动后头部下缘出现细线和阴影。对比菜单浮在主体之上。
- 结果表第四列标题由“上次”改为“对比”，与对比选择和图例一致。
- 变化列：升高为绿 `#157038` 并带 ▲，降低为红 `#C22A2A` 并带 ▼，不变为灰；变化达到对比值的 20%（含）时加粗并加同色浅底（`#E8F5EC`／`#FDECEB`）。颜色在所有底色上 ≥ 5:1，方向同时由箭头表示，不只靠颜色。悬停显示相对变化百分比。浅底块向右多出 6px 以让数字与普通变化值对齐，所以变化列（含表头）留 6px 右内边距，浅底块止于表格右边缘，不越过行线。
- 表下说明写明“颜色只表示升降，不代表好坏；加粗带底色表示变化达到对比值的 20%”。
- 会话记录每条显示“第 N 次 · 时间 · 项数”，与结果标题和对比菜单的编号一致。
- 会话记录的行宽固定为卡片宽度（`minmax(0, 1fr)`），长 SMILES 以省略号截断，结果主体不会横向滚动；否则性质名称会被推出左边界。

### 使用说明

- 结构：一句话概述 → 三步上手卡（画出结构／选择性质／运行并对比）→ 吸顶目录（输入结构、结构信息、预测内容、读懂结果、运行与对比、导出、快捷键）→ 每个主题一张白卡，卡头用页面统一的浅蓝图标块 → 底部黄色提示“模型预测值，需实验验证”。辅助栏底色为面板浅灰，卡片为白。
- 输入结构：四种方式的图标列表 + 浅蓝提示框（连接点写法与示例）。
- 结构信息：两列词汇表（名称与单位｜说明）。
- 预测内容：三组各一块通道色浅底卡，左侧通道色竖线；每项右侧列出刻度条显示区间。
- 读懂结果：左侧画出与结果表相同的标记（刻度条、升降、变化达到 20%、未返回），右侧解释。
- 快捷键：两列表格，按键用键帽样式。
