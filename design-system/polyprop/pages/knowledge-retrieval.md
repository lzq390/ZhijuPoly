# 知识检索页面规范

## 定位与基线

- 页面是聚合本地知识、在线文献抽取和 PDF 静态演示的科研工作台，不是营销落地页。
- 视觉与交互基线为 2026-08-12 确认的 `knowledge-retrieval-module-snapshot.html`；生产页面只复用布局与交互，不使用快照模拟数据或状态控制器。
- 本地知识库是默认生产能力；在线文献是异步生产能力；PDF 相似度始终标记为 `Static Demo`。

## 布局与视觉

- 复用公共 AppShell 的 276px 侧栏；模块内容满高、禁止页面级横向滚动。
- 冷灰蓝科研背景采用 32px 细网格；主工作列宽 `min(100%, 1040px)`，工作面为白色、14px 圆角、细边框和浅阴影。
- 正文基准 16px，页面标题 20px，工作面标题 18px，结果标题 16px；科学字段和计数采用全局等宽字体。
- 蓝色用于主操作和选中态，青色用于数据来源与准备状态，紫色只用于 PDF Demo，红色和琥珀色只用于错误或风险边界。
- 三种模式右上状态统一显示“准备就绪”，不叠加说明型操作；服务配置和 PDF 静态演示边界仍在表单工作面内明确呈现。
- 禁止巨型 Hero、玻璃营销卡、装饰粒子、固定宣传指标和大卡套小卡。

## 模式与状态

- 三种模式使用标准 tab 语义和方向键导航；首次访问时挂载，之后只隐藏不卸载，以保留表单、结果、在线轮询和 PDF 定时器。
- 本地检索明确展示实际字段和排序语义；详情提供记录概览、反应信息、原文与溯源。
- 本地检索采用组间 AND、组内 OR：`;` / `；` 分隔必选条件，`|` / `｜` 分隔同义词；文本 `AND` / `OR` 仅作兼容。输入框下实时展示逻辑预览，普通空格和逗号不作为逻辑符。
- 不完整逻辑表达式必须就地报错并禁止提交；旧 `terms[]` 和重复 `term` 深链按多个必选组解释。
- 在线检索展示真实任务阶段、处理论文数和结构化记录；示例回退必须醒目标注，合成模式不得补造论文溯源信息。
- PDF 首屏固定说明只校验类型和文件名、不读取或上传内容；结果、DOI 和相似原因均标注为固定演示资产。
- 等待、加载、成功、空结果和错误使用稳定工作面；错误保留输入上下文并提供就地恢复动作。

## 详情抽屉与响应式

- 抽屉默认 380px，桌面端支持拖拽和方向键调宽，范围 320–560px；关闭后保留内容并提供贴边重开入口，本地与在线记录详情入口采用竖排文字和蓝青选中反馈。
- 支持 Escape 关闭、焦点恢复、`aria-hidden`、`inert`、`role="dialog"`、移动端焦点约束和 `prefers-reduced-motion`。
- `>=1280px` 时主区为抽屉让位；`900–1279px` 抽屉覆盖主区；`<900px` 使用带遮罩的模态抽屉；`<680px` 表单、统计、分页和结果卡改为单列。
- 必须在 1440×900、1024×768、390×844 下保持无文字重叠、横向溢出或不可达操作。
