# MD 模拟页面设计规范

页面：MD 模拟 `/md-simulation`
参考实现：`PolymerMdSimulationPage`、`PolymerMdFormalPage`、`MdSimulationDemoPage`
更新时间：2026-10-23
范围说明：本规范不适用于独立的“单体 MD 模拟” `/monomer-md-simulation`。

---

## 正式计算与示例演示

- `/md-simulation` 默认进入正式聚合物 MD 计算；公共页面标题和侧栏标签保持“MD 模拟”。公共页头只保留浏览记录入口，服务状态与刷新放在工作面之外的紧凑工具栏。
- 页面参照单体 MD 工作台：主工作面稳定包含图标、随页签变化的标题与说明，以及等宽的“模拟配置 / 任务中心 / 结果分析”三个页签。标准列宽1040px，2K列宽1560px；工具栏与页头不随正文滚动。
- “正式计算 / 示例演示”是模拟配置内部的两张运行模式卡，桌面横排、移动端竖排。示例演示复用 `MdSimulationDemoPage` 的嵌入视图，配置和结果接入公共主页签，不再重复挂载模块页头、工作面外框或一级导航。切换模式与工作区保留正式草稿、示例上下文及已选任务，不自动提交。
- 模式切换使用同一个常驻选中背景，按平台 `--np-motion-tab` 时长在两张模式卡之间平滑移动；移动端随竖排改为纵向滑动，减少动态效果偏好下立即到位。
- 正式配置与独立聚合物 MD 环境共用 `polymer_md/user_configuration.json` 的完整选项和执行映射，不能使用旧示例的六字段配置代替。包含五种聚合物模型（均聚、交替、随机、嵌段、共混），原子数／聚合度／分子量三种链长，以及各模型的组成、比例、嵌段序列和组分链数设置。
- 正式任务使用现有认证访问同源 `/api/v1/polymer-md`，由部署的聚合物 MD 服务提供计算接口。本地开发通过 Vite 的 `DEV_PROXY_TARGET` 指向该服务；生产环境通过同源 API 转发接入，服务不可用时保留配置并显示状态。
- 体系条件包括温度、压力、链规模、首末端端基与立构规整性；力场保留 GAFF、GAFF2、GAFF2_mod、Dreiding、Dreiding_UT。量化准备保留几何优化方法及基组、原子电荷模型及方法／基组、极化率方法／基组和适用性说明。
- “模型与条件”的默认 8 个参数合并为同一网格：第一行温度、压力、每链目标原子数、链数，第二行首端、末端、立构、力场；标准屏与 2K 都为四列，窄屏改两列／单列。根据建模方式继续隐藏不适用的原子数或链数字段。区块介绍、参数帮助和体系上限说明最多一行，完整说明保留在 title 中；校验错误保持可换行。
- “量子化学方法”的 7 个字段同样采用四列两行（4+3），使用单行字段帮助，移除逐字段的参数说明展开框。完整方法说明、适用性与 Br/I 锁定覆盖规则保留在帮助 title 中；未使用的方法仍保留选择。正式计算下拉菜单只显示选项名称，不显示选项说明副文案。
- 基础 14 项物性默认包含。追加计算保留 RNEMD 热导、静态折射率、热扩散率、Tg、SP/CED；热扩散自动包含热导，SP/CED 联动并要求至少两条链，热导开启后显示传热方向。平衡时长、采样间隔、随机种子与温度扫描方案继续由平台管理，不扩展成任意可编辑输入。
- 游客可以浏览和编辑完整本地配置；服务能力、本人任务和正式提交继续使用原有认证。未登录时不请求私有 MD 接口；切换示例后返回正式模式应恢复本标签页的配置草稿。
- 正式任务保留请求恢复、阶段状态、质量检查、日志、物性曲线、真实轨迹、原子距离、产物下载及清理／删除确认。不得以示例结果填充正式任务结果。
- 任务、历史与运行日志在本轮请求完成后调度下一次刷新，慢响应不得被定时轮询持续作废。正式轨迹标注当前实际阶段、返回帧序号与距离分析的周期边界状态；服务限制导致无法提交时，应展示对应的力场或体系规模错误。
- 正式结果采用“概览 / 曲线 / 构象 / 输出文件”四个二级页签。概览保留科学指标、阶段日志、质量与运行证据；曲线只展示实际返回的采样序列；构象保留阶段选择、翻帧、原子距离及周期边界；输出文件保留真实产物下载和清理。取消与删除任务动作始终跟随当前任务，不虚构队列位置或总进度。
- 配置按组成、体系条件、量化准备、计算内容分区；底部统一提交栏显示校验／服务状态、恢复默认和正式提交入口。所有运行模式与页签支持键盘访问；公共页头保持20／28px，2K同步提高输入、说明、任务及结果字号。
- 工作面沿用公共冷灰／白色／蓝青主题、1040px／1560px 工作列和公共页头断点。参数分组使用标题及细分隔线，避免装饰渐变和重复外框。
- 正式计算的链长、端基、立构、力场、量化方法／基组、嵌段组成和轨迹阶段复用项目的 `WorkbenchSelect`，沿用浮层、选中勾、方向键、Escape、点击外部关闭和焦点规则。保留原帮助／错误关联与全部科学选项，历史未知选择显式显示，不能静默回退第一项。参数说明、基础物性和结果证据继续使用原生 `details/summary`，统一为蓝灰表面和旋转箭头，保留日志按需读取行为。

以下第 1–6 节描述示例演示模式；正式表单的字段、范围、草稿及任务契约以对应聚合物 MD 配置和校验实现为准。

## 统一字体

- 正式配置、任务列表、正式结果、嵌入示例与确认弹窗共用 `polymer-md-typography.css`，布局样式不再分散声明字体。标题使用平台 Exo 字体栈，正文、中文标签与按钮使用 IBM Plex Sans 字体栈；中文明确回退到系统的 PingFang SC、Microsoft YaHei 或 Noto Sans CJK SC。
- SMILES、任务 ID、日志、数字输入、物性数值和图表刻度统一使用 `--font-mono`（Roboto Mono）。包含中文的单位、状态、轨迹说明与轴标题使用正文字体；科学字符串单独包裹，避免整行中文继承等宽字体。
- 常规字重使用 400、600、700；公共模块页头继续遵循 MASTER。中文标签不增加字距，不依赖 650、680、720 等中间字重合成层级。
- 输入值和下拉框当前值使用 400 字重，选项列表标题使用 600；避免同一表单中数字为常规体、下拉值为粗体。中文占位提示使用正文字体，实际科学值保留等宽字体。阶段、曲线统计、轨迹说明、加载状态与页脚也必须引用同一字号变量，不能继续沿用旧示例的 8–10px HTML 辅助字号；SVG 图表刻度按自身坐标系缩放。
- 标题、关键标签与实际数据使用 `ink`，说明／单位／来源使用 `muted`；`faint` 只用于非关键装饰。状态分别使用公共 `info/success/warning/danger/neutral` 文字、浅底及边框角色，主操作反相文字使用 `on-accent`。科学曲线和元素图例保留数据配色。
- 原生 `details` 展开后的常态文字保持中性色，悬停和聚焦才使用蓝色反馈。共享示例控件的旧文字色与装饰渐变由页面 palette 统一，公共主题变量是唯一颜色来源；确认弹窗通过 `np-workbench-theme` 继承同一主题，不使用脱离页面的旧颜色 fallback。

## 1. 页面定位与数据边界

- 页面用于展示分子动力学配置、六阶段流程、热力学曲线、最终帧轨迹及原子距离分析。
- 页面默认使用真实示例 SMILES，所展示的体系、曲线和轨迹来自该示例结构已完成的真实 MD 计算。“演示”仅指页面用于展示完整分析流程，不得将结果描述为固定、占位或伪造数据。
- 页面文案不暴露内部数据路径，不使用“接口”“fixture”“快照”“前端/服务端”等面向开发的描述，不提供尚未支持的轨迹、日志或结果下载操作。
- 输入中的“目标原子数”与结果中的“原子数”分区展示，计算输出以结果页记录的体系规模为准。

## 2. 工作台骨架

- 页面进入 AppShell 的满高 `p-0` 科研工作台分支，由页面内部负责滚动；侧栏承担模块切换，不增加返回首页卡片。
- 复用结构工作台的冷灰蓝网格、蓝青 token、白色工作面、14px 圆角、细边框和浅阴影。
- 标准主工作列为 `1040px`，字体遵循上面的统一字体规范。
- 顶部状态只呈现“检查中”“准备就绪”或“读取失败”；准备状态使用绿色圆点和蓝灰文字，读取失败提供刷新动作。
- 嵌入示例时由公共“模拟配置 / 结果分析”承载输入和结果，不增加第二套工作面或模块页头。独立组件保留“结构输入 / 模拟结果”导航能力，供现有组件与结果测试复用。只有成功结果存在时才表达完成，首次运行失败不得误标为完成。
- 页面纵向滚动由整宽滚动层承载，滚动条固定在工作区最右侧；`1040px` 内容列只负责居中和限宽。

## 3. 结构与参数

- SMILES 输入提供复制、清空、导入共享结构和编辑共享结构；本页不挂载新的 Ketcher 编辑器实例。
- 2D 预览使用安全 SVG 渲染和统一网格背景。初始化、导入共享结构或完成输入后刷新预览；新预览取消旧请求，局部失败不影响页面准备状态。
- 无会话草稿时直接预置推荐示例 SMILES；旧草稿中的 SMILES 为空或仍为历史占位值 `CC` 时自动迁移为真实示例，同时保留其余参数。迟到的默认响应不得覆盖用户已经修改的表单。
- 热力学条件、体系规模和力场收进右上角“参数设置”浮层；浮层沿用结构工作台标准 utility layer，支持点击外部或 Escape 收起并恢复焦点。
- 参数浮层遵循统一字体分工：标题使用 Exo，中文分组标题、说明和字段标签使用 IBM Plex Sans，参数数字使用 Roboto Mono。标题、标签和说明分别沿用统一的 `18/24px`、`12/15px`、`11/14px` 标准屏／2K 字号，不得让中文字段标签继承等宽字体或额外字距。
- 力场使用与正向聚合类型选择一致的自定义组合框：图标、双行选中摘要、向下展开的浮层选项和完整键盘导航；不接受新的任意文本输入，已保存的自定义值可作为兼容选项继续显示。触发器下方不再重复展示独立说明。
- 会话草稿仅保存 `smiles`、`temperature`、`pressure`、`n_atom`、`n_chain`、`forcefield` 六个字段。
- 表单边界与后端保持一致：温度 `(0, 5000] K`，压力 `(0, 100000] atm`，目标原子数 `100–500000`，链数 `1–10000`，SMILES `1–4000` 字符，力场 `1–64` 字符。
- 结果页不提供单独的“清空结果”操作；“重置”恢复默认值并删除草稿和结果。

## 4. 主工作区结果

- 点击“开始模拟”后立即切换到一级“模拟结果”页签；加载、失败、结果准备进度和成功结果都在同一主工作面稳定呈现。准备进度只说明结果读取与整理过程，不使用实现层术语。
- 结果工作面包含 `概览`、`曲线`、`轨迹` 三个带图标和用途说明的分析页签。概览以运行标识、状态、摘要指标和 EQ 阶段形成清晰层级；曲线使用一个连续分析面统一摘要、选择器、图表与统计，避免重复卡片和多层边框；轨迹包含交互 HUD、坐标轴、原子对选择槽和 PBC 分析状态。
- 轨迹双列在桌面与 2K 下必须等高。距离分析区预留固定输出槽（桌面 `360px`、2K `540px`），等待、加载和成功曲线只在槽内替换；预留高度应让曲线接近容器宽高比，减少左右空白，且不得因选择原子或返回结果改变整行高度。
- Canvas 保留拖拽旋转、滚轮缩放、点选原子和 DPR 自适应；原子编号输入提供键盘等价操作。第三次点选替换最早的选择，重复原子不得发起距离计算。
- 新运行、原子选择变化、清空、重置和卸载都必须取消对应旧请求；取消或过期响应不得回写。
- 参数变化保留旧成功结果，并标记“结果对应上次输入”；新请求失败时也不得清除上一份成功结果。

## 5. 响应式与 2K

- `<900px` 时内容列保留 `12px` 两侧安全区，参数浮层使用底部模态布局；摘要、曲线选择和轨迹分析按可用宽度改为单列。
- `(min-width: 2000px) and (min-height: 1120px)` 下主工作列扩展为 `1560px`，网格从 `32px` 放大至 `48px`，文字、间距和控件按现有工作台约 1.5 倍规则提升。
- 2K 参数浮层扩展至 `900px`，结果概览使用双列信息布局，轨迹和距离分析并排显示。

## 6. 验收清单

- 默认数据读取、失败刷新、迟到响应保护、字段边界、草稿恢复和重置行为正确。
- 开始模拟后立即切换结果页签；结果准备、失败保留旧结果、“对应上次输入”提示和一级页签往返行为正确。
- 密度/热力学空序列安全；`g/cm³`、`kcal/mol`、`Å`、`ps` 等单位统一。
- 轨迹支持尺寸变化、DPR、旋转、缩放、点选、第三点替换、原子编号输入和距离计算取消。
- 1920×1080、2560×1440、1440×900、1024×768、390×844 下无横向溢出、文字重叠、图表裁切或不可达操作。

## 公共页头与基础主题（2026-09-10）

- 使用 `ModulePageHeader`、`.np-module-page` 和 `.np-module-page-body`，遵循 [MASTER](../MASTER.md) 的62／84／60px固定页头；标题位置和字体不由本页断点重复定义。
- 正文从页头下方开始，沿用本页工作列、滚动区、抽屉、控件密度及科学数据语义色。
- 基础颜色、边框、焦点和主表面引用公共工作台变量；本页业务规范不覆盖公共标题坐标。
