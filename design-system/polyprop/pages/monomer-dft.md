# 单体 DFT 工作台

## 定位

单体 DFT 是科研计算工作台。底层计算引擎、模型版本与调度组件属于实现信息，不在用户界面中展示；页面只负责准备计算、管理任务和解释结果，不在前端重建科学数据。

页面复用结构工作台的冷灰蓝网格、白色工作面、蓝青强调线、细边框和浅阴影。DFT 由 AppShell 按满高科研工作台承载，页面内部的 `.np-dft-scroll-region` 是唯一纵向滚动层。

页面标题下方的服务工具栏与单体 MD 使用同一结构：左侧只保留渐变引导线，右侧仅承载状态与刷新操作。不得展示并发数、排队上限、活跃任务数或计算节点名称。计算暂未开放时，顶部使用灰点与“暂未开放功能”，并在独立说明条中明确仍可查看历史记录和已有结果。

## 信息架构

主工作面包含三个一级页签，并使用完整的 `tablist`、`tab`、`tabpanel` 语义：

1. 计算配置：结构、适用体系、电子态、性质和初始构型设置。
2. 任务中心：当前任务、进度、操作和共享任务历史。
3. 结果分析：已提交参数和三类科学结果。

结果分析再分为三个二级页签：概览、曲线与频率、原子数据。一级和二级页签都支持左右方向键、Home 和 End。页签切换不得中断任务同步、清除结果或修改任务链接。

提交成功、合法任务链接恢复以及选择历史任务后进入结果分析。没有选中任务时默认显示计算配置。

任务中心页签不展示任务数量徽标。任务历史固定每页 10 条，筛选或翻页不切换当前结果。
当前任务操作区不提供复制链接按钮；任务选择与浏览器地址同步仍用于页面恢复。操作区末尾固定提供一个“下载结果”入口，将保留的结果文件作为单个压缩包下载；任务未完成或结果文件不可用时，按钮保留但禁用。结果页不再展示逐项文件、耗时或运行记录。

## 结构输入

- DFT 页面不挂载 Ketcher，也不保留第二个画板实例。
- 可见的 SMILES / PSMILES 草稿是唯一提交内容，并同步到共享 `structure.smiles`。
- 提交时标准化当前可见草稿，禁止再次读取隐藏画板覆盖输入。
- 2D 预览通过安全 SVG 接口防抖生成；新输入必须取消或隔离旧响应。预览卡片使用“标题行 + 填满剩余高度的画布”两行布局，图片受固定内层约束并使用 `object-fit: contain`，禁止以 SVG 自然高度溢出或在画布下方留下独立空白。预览失败不得阻止后端继续验证任务。
- 活跃任务期间锁定整份请求配置。终态后可以修改或按原请求重跑。

## 字体与颜色

| 内容 | 字体 |
|---|---|
| 页面标题、工作面标题、分区标题 | Exo / `--font-heading` |
| 中文正文、标签、按钮、说明 | IBM Plex Sans 中文回退 / `--font-body` |
| SMILES、任务 ID、数值和坐标 | Roboto Mono / `--font-mono` |

页面只使用七个稳定字号角色：微标注、辅助说明、正文、字段、面板标题、分区标题和工作面标题。禁止在单个卡片内另起相近字号；中文状态值使用正文字体，只有数值和技术标识使用等宽字体。说明文案优先单句表达，不暴露 iframe、隐藏画板或接口字段名等实现细节。

交互主色只使用蓝青。红色只表达错误或危险操作，黄色只表达警告，绿色只表达成功或就绪。普通计算方案、属性或页签选中态不得引入紫色。

计算方案下拉只按用途区分，例如通用有机分子、带电与多重态体系、含钯催化体系和反应路径与活性结构。版本相近且用途相同的模型合并为一个选项；真实模型名称与 ID 只保留在提交数据中。所有下拉使用统一的工作台弹层，提供选中标记、说明文字、禁用态、视口边缘自动翻转，以及方向键、Home、End、Enter 和 Escape 操作。

所有交互控件使用结构工作台的蓝色 `focus-visible` 环。状态不能只依赖颜色：图标、文本、徽标或图例必须同时表达语义。

## 状态规范

服务工具栏对外只使用正在检查、准备就绪、暂未开放功能、服务准备中、暂缓新任务、任务繁忙和暂时不可用等产品语言。计算暂未开放时使用灰点状态，同时通过独立说明条明确提交限制。能否提交仍由服务返回的完整状态共同决定，但接口字段名和发布术语不得出现在界面文案中。

任务进度展示真实 stage、百分比和队列位置，并提供等价 `progressbar` 语义。操作必须明确区分：

- 非终态任务取消。
- 终态任务按保存请求重跑。
- 永久删除任务记录、结果和分享链接。

运行中与取消中的任务使用稳定进度工作面；失败或取消且没有结果时展示对应终态，不显示等待结果文案。结果始终标注属于已提交参数；修改草稿不能覆盖当前结果。

输出文件状态仅用于判断“下载结果”是否可用，不在界面暴露文件清单、内部状态、服务端路径、内容哈希或媒体类型代码。

## 科学展示

- 3D 只渲染计算返回的显式坐标，不从 SMILES 推导几何。
- 初始、优化轨迹和最终帧去除重复端点；帧类型按钮提供 `aria-pressed`。
- 单点计算只在固定坐标上评估性质，不生成优化轨迹；界面只展示初始与最终入口，并隐藏轨迹滑块。几何优化任务才展示随优化步骤变化的中间坐标。
- 3D 容器使用 ResizeObserver，在页签显示、容器尺寸变化和密度切换后 resize 并 render；加载失败必须提供显式重试。
- 虚频阈值使用计算结果返回值，极小值结论直接采用结果中的判定。频率谱必须同时提供文字计数和图例。
- 显式同位素提示只出现在频率语境。旧版初始构型准备状态未知时，不得推断为已优化或未优化。
- 原子表只在自身容器横向滚动，序号和元素列固定；页面不得产生横向滚动。
- 模型名称、模型哈希、运行环境和调度实现字段不得展示。

原生 2K 断点固定为 `(min-width: 2000px) and (min-height: 1120px)`。命中后必须同时放大字体、控件、间距、图表、3D 和表格，不能只扩展内容列。

内部网格以工作台容器宽度为主要依据：

- 小于 900px：12px 页面安全边距，结构与图表改为单列。
- 小于 560px：字段与主操作改为单列，提交按钮满宽；一级页签隐藏辅助说明；三个结果页签使用紧凑三列布局并隐藏辅助说明。
- 原子表保留局部横向滚动，不改变主页面滚动边界。

## 验收视口

视觉验收覆盖 2560×1440、2048×1152、1920×1080、1440×900、1024×768 和 390×844。每档检查：

- 页面 `scrollWidth === clientWidth`。
- 仅 `.np-dft-scroll-region` 承担纵向滚动。
- 长任务 ID 和 SMILES 不撑破布局。
- 2K 档实际命中 1560px 内容列和完整大屏字号层级。
