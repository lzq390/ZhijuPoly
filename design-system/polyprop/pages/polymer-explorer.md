# 聚合物相似性探索页面设计规范

页面：聚合物相似性探索 `/explorer`
参考实现：`PolymerSimilarityExplorerPage`
更新时间：2026-08-31
覆盖规则：复用结构工作台的共享画板、参数浮层、结果抽屉、响应式及 2K 规则。

---

## 1. 页面定位

聚合物相似性探索用于对单一共享结构运行数据库匹配，保留两种口径：

- 结构相似：按分子指纹相似度检索聚合物。
- 性能相似：先计算所选性质的目标值，再按数据库性质接近度检索聚合物。

九项性质的直接预测已迁移到“均聚物性质预测”，本页面不再提供预测结果入口。

## 2. 结构画板

- 完整复用 `useTgStructureCanvas` 与 `StructureCanvasSurface`。
- 保留加载 `*CC*` 示例、图片导入、清空、生成 SMILES、2D/3D 切换和复制能力。
- 页面标题、画板尺寸、工具栏密度、蓝灰网格主题和 2K 放大与结构工作台一致。
- 任意时刻只挂载一个共享 Ketcher iframe；离页前执行 `syncBeforeLeave()`。
- 普通 SMILES 与带 `*` 连接点的重复单元均可用于检索。

## 3. 探索参数

- 工具栏只增加“探索参数”，不显示工作台的“功能参数/AI 助手”。
- 参数浮层紧凑展示探索方式、相似度阈值、搜索数量和可选性能指标。
- 默认参数：结构相似、阈值 `0.7`、搜索 `10` 条。
- 相似度阈值范围 `0–1`；`0` 表示不过滤，`1` 表示最严格。
- 搜索数量范围 `1–100`。
- 性能相似模式只允许选择一个指标，指标目录与均聚物性质预测共用同一前端配置。

## 4. 数据契约

- 继续调用 `POST /api/v1/query/smiles`，不修改后端接口。
- 结构相似提交 `match_mode: "structure"`、`property_name: null`。
- 性能相似提交 `match_mode: "property"` 和所选 `property_name`。
- 提交前同步并标准化画板结构；空结构不提交。
- 结果固定保存本次 SMILES、模式、阈值、数量和性质快照。

## 5. 结果抽屉

- 提交后立即打开结构工作台同款结果抽屉。
- 抽屉覆盖 loading、失败、空结果和成功结果；关闭不清除数据。
- 发生过检索后才显示右侧重开把手，重开不重复请求。
- 结果卡展示二维结构、名称、SMILES、匹配度、匹配指标和数据来源。
- 结果摘要首卡展示提交结构；长 SMILES 默认折叠并可展开，下方查询耗时与探索口径并列。
- 性能相似结果额外展示查询结构的模型预测值，但不伪造置信区间或科学量程。
- 当前结构或参数变化后保留旧结果，并标记结果属于上次提交快照。

## 6. 响应式和 2K

- AppShell 使用满高、无内边距、无横向溢出的工作台容器。
- 抽屉并排/覆盖模式、拖拽范围、键盘控制、焦点循环和移动端底部弹层沿用工作台规则。
- 参数浮层在窄屏改为单列，性能指标由三列降为两列。
- 使用 `(min-width: 2000px) and (min-height: 1120px)` 同步放大字体、控件、参数面板、结构画板和结果媒体。

## 7. 验收清单

- 侧栏、工作台功能入口和页面标题均显示“聚合物相似性探索”。
- `/explorer` 深链保持兼容并正确高亮侧栏。
- 两种相似模式提交正确 payload。
- 画板模块之间切换前同步共享结构，应用中始终只有一个 Ketcher iframe。
- 结果关闭后可通过侧边把手重新打开。
- 结果快照、错误、空结果、2D/3D 和移动覆盖抽屉均可用。
- 标准与 2K 视口无横向溢出、遮挡或裁切。
- 完整前端测试、生产构建和 `git diff --check` 通过。
