# 聚合物性能探索页面设计规范

页面：聚合物性能探索 `/explorer`
参考实现：`PolymerExplorerDesktopPage`
更新时间：2026-08-31
覆盖规则：本页面覆盖 Master 布局，采用居中科研工作区 + 右侧分析抽屉。

---

## 1. 页面定位

聚合物性能探索是一个高密度科研工作台，用于绘制聚合物结构、同步 SMILES、预览真实 3D 构象，并运行结构相似和性能相似任务。性质预测已迁移到独立的“均聚物性质预测”模块。

验收目标：

- 桌面端保留左侧平台侧栏。
- 右侧工作区保留上下 padding，分析抽屉可以从工作区最右侧弹出。
- 主编辑列居中，并且明显窄于可用工作区。
- 两侧留白保持为空背景，不放工具、卡片或结果。
- 运行后的结果进入右侧分析抽屉，不做成全宽营销式内容区。

---

## 2. 布局

- AppShell 的 explorer 模式不使用水平 padding，但保留垂直 padding：`py-5 md:py-8`。
- 页面根节点填满 AppShell 内容区高度。
- 居中 shell 使用 `padding: 0 clamp(24px, 6vw, 160px)`，背景使用 `--color-bg-app`。
- 主内容列宽度为 `min(100%, 1040px)`。
- 页面标题使用紧凑 `16px`，放在工作区左上角。
- 模块顶部操作按钮在居中列右侧对齐。
- Ketcher 画板和 SMILES 胶囊上下堆叠。
- 分析抽屉绝对定位在工作区右边缘；默认宽度 `380px`，可拖拽范围 `320px` 到 `560px`。

---

## 3. 核心界面

### 3.1 顶部操作按钮

- 按钮包括：`导入图片`、`清空画布`、`生成SMILES`、`3D构象` 或 `2D画布`。
- 所有按钮使用同一套小型描边样式：白色背景、细边框、高度 `30px`、圆角 `6px`、Lucide 图标 + 文本。
- 3D 切换按钮不能使用特殊蓝色填充样式，必须和其他按钮视觉一致。
- 按钮组需要右对齐，但不能贴到浏览器最右侧。

### 3.2 Ketcher 和 3D 翻转卡片

- 默认正面是 2D Ketcher iframe。
- 背面是真实 `StructurePreview3D` 查看器。
- 打开 3D 前必须先从画布同步 SMILES。
- 没有结构时不翻转，显示反馈提示用户先绘制、导入或输入结构。
- 2D 和 3D 切换不能丢失输入、画布状态或已同步 SMILES。

### 3.3 SMILES 胶囊

- 默认 SMILES 为空。
- 空状态禁用运行 split button，并设置 `opacity: 0.45`。
- 有内容时显示复制和清空浮动按钮。
- placeholder 可以包含 `*CC*`、`CCO` 等示例，但示例不是默认值。
- 反馈文本留在胶囊区域内部。

### 3.4 模式 Split Button

- 默认模式为 `结构相似探索`。
- 下拉选项包括：`结构相似探索`、`性能相似探索`。
- 二级属性菜单必须使用可读的 slate 系列深色文本，避免白底白字或低对比。
- 属性标签需要清晰表达科学单位：
  - `玻璃化转变温度 (Tg)`，单位 `°C`。
  - `熔融温度 (Tm)`，单位 `°C`。
  - `热分解温度 (Td)`，单位 `°C`。
  - `热分解失重率 (%)`，短标签 `Wloss`。如果表达的是达到 5% 失重时的分解温度，应写作 `热分解温度 (Td5%)`，不要写成 `热分解失重 (Td 5%)`。
  - `断裂伸长率 (ε)`，单位 `%`。
  - `断裂拉伸强度 (σ)`，单位 `MPa`。
  - `O2 渗透率 (PO2)`，单位按数据源展示。
  - `CO2 渗透率 (PCO2)`，单位按数据源展示。
  - `H2 渗透率 (PH2)`，单位按数据源展示。

## 4. 数据和交互规则

- 结构相似调用现有 `/query/smiles`，参数 `match_mode: "structure"`。
- 性能相似调用现有 `/query/smiles`，参数 `match_mode: "property"`，默认属性为 `Tg`。
- 导入图片只有在 Ketcher 确认写入结构并返回非空 SMILES 后，才能显示成功。
- 导入图片前必须保存当前画布快照；失败时尽可能恢复旧画布和原 2D/3D 状态。
- 导入成功后，SMILES 文本使用 Ketcher 确认返回的值，不能使用过期 fallback。
- 清空画布应同时清空 SMILES、重置 3D 翻转状态、关闭分析抽屉，并显示局部反馈。
- `*CC*` 等聚合物端基输入应保留，不做错误剥离。

---

## 5. 分析抽屉

- 抽屉标题为 `分析工作台`。
- 抽屉贴到工作区右边缘时，不使用装饰性外边框或卡片重阴影。
- Loading 状态使用骨架卡片。
- 空状态给出简洁下一步。
- 错误状态使用同一套面板布局，并使用红色强调。
- 结构和性能结果卡展示结构图、SMILES、相似度或匹配指标、数据来源。
- 抽屉内容可以滚动，但抽屉头部和关闭按钮位置保持稳定。

---

## 6. 响应式

- 桌面宽屏是视觉优先级最高的场景。
- 小于 `900px` 时，两侧留白收起，主布局允许滚动。
- 当前移动端兜底中隐藏右侧分析抽屉和拖拽条。
- 顶部操作按钮可以换行，但文字必须可读，不允许重叠或被截断。
- Ketcher 工具栏、画板、SMILES 胶囊和运行按钮在窄屏下必须保持最小可用尺寸。

---

## 7. 验收清单

接受聚合物探索 UI 修改前，逐项检查：

- `/explorer` 保留平台左侧侧栏。
- 工作区上下 padding 可见，水平留白只显示背景。
- 宽屏下主内容列居中且明显收窄。
- 分析抽屉从工作区最右侧弹出。
- 默认 SMILES 为空。
- 导入图片失败时能恢复旧画布状态。
- 3D 切换前会同步 SMILES。
- 两种模式都能运行，并覆盖 loading、错误、空结果、成功结果。
- 指标名称、缩写和单位清晰可读，不出现 `Td 5%` 这类含义混淆写法。
- `npm run build` 和 `git diff --check` 通过。
