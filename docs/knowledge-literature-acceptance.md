# 知识检索文献功能的复验范围

本提交提供功能源码和隔离回归测试。真实来源数据库的验收汇总、源记录标识及科学材料记录保存在原任务证据目录，本文件不转载这些数据。

## 源码集成约束

- 保留主线结构库、用量和权益迁移历史；文献投影按独立 `0024_literature_projection` 扩展。
- 旧身份回执保持各自版本边界。文献运行与备份使用完整的已登记账本。
- 导入、发布、回滚、文件读取和浏览器抽屉分别验证；服务失败时保留明确的不可用状态。
- 本地回归仅使用独立临时 PostgreSQL 和合成样例，原任务数据库及 MinIO 对象不作为回归输入。

## 运行前置条件

部署、角色配置、数据库迁移、真实数据导入和对象存储备份属于单独的运维步骤。源码合入及隔离测试通过不代表这些步骤已经执行，也不代表已完成真实数据或科学验收。

配置和维护接口见 [知识检索文献功能说明](knowledge-literature.md)。
