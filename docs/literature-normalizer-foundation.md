# Literature normalizer foundation (local review only)

This independent library has no database, storage client, network, route, or UI dependency.
It preserves zero-valued yield-only process observations and counts material quotations
in evidence capabilities. Version literature-v2 separates the changed immutable snapshot
identities from literature-v1; it does not migrate, republish, or reinterpret old snapshots.

The synthetic standard-library regression suite runs with backend on sys.path:
python -I -S -B -c 'import sys,unittest; sys.path.insert(0,"backend"); sys.path.insert(0,"backend/tests"); unittest.main(module="test_literature_normalizer")'

This commit intentionally does not wire the library to API routes or the old literature
0020 contract. Before feature integration, reconcile the canonical migration ledger,
publication normalizer compatibility, authorization/backup contracts, asset dependencies,
and actual database tests. The local MD candidate is separate and is not published.
No database or scientific acceptance result is claimed by these pure tests.
