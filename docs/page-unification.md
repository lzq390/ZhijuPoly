## 页面契约

`ModulePageHeader`接受原生h1属性并输出独立页头。模块根节点使用`.np-module-page`，正文标记`.np-module-page-body`。根节点统一预留页头高度，正文自身不再重复设置标题占位。默认页头位于正文滚动容器外，14页保持固定页头；单体正向聚合按后续业务要求保留根节点整体滚动，是MASTER明确列出的唯一例外，单次／批量模式标题随正文滚动。

| 视口 | 左／上边距 | 字号／行高 | 页头占用 |
|---|---:|---:|---:|
| 普通 | 20／22px | 20／30px | 62px |
| 宽≥2000且高≥1120 | 36／30px | 28／42px | 84px |
| 宽≤899 | 16／20px | 20／30px | 60px |

字重750、颜色#0b1f3a、Exo标题字体及中文回退保持一致。标题坐标相对于AppShell右侧工作区；手机端扣除平台顶栏。正文的容器断点、控件密度、画板尺寸、工作列与抽屉仍由业务页面管理。

基础颜色、状态色、边框、焦点、表面圆角和阴影来自`workbench-theme.css`，各页私有变量引用公共角色。主工作面统一白色；状态提示同时复用文字、浅底和边框角色，保留业务控件原有尺寸。科学类别、原子元素和优化目标色保持原语义。浅底状态文字另用深色前景，避免直接将明亮状态点颜色用于小字。

## 可复现验证

在`frontend`目录安装依赖及浏览器，启动本地前端后执行：

```bash
npm ci
npx playwright install chromium
npm run dev -- --host 127.0.0.1
```

另开终端执行：

```bash
PAGE_BASE_URL=http://127.0.0.1:5173 npm run test:pages
DRAWER_BASE_URL=http://127.0.0.1:5173 npm run test:pages:focus
PAGE_BASE_URL=http://127.0.0.1:5173 npm run test:pages:states
npm test
npm run build
git diff --check
```

浏览器脚本只允许本地GET／HEAD请求；API写入、任务提交及外部请求被拦截。服务失败场景使用本地503响应夹具，核对最终生效的错误文字、背景和边框色。高通量只操作前端预设演示数据。任务成功结果、轮询、深链接和3D预览继续由现有组件／Hook夹具测试覆盖。

支持以下环境变量：

- `PAGE_ARTIFACT_DIR`：JSON坐标报告和截图目录，默认`/tmp/nexpoly-page-consistency`。
- `PAGE_CHROMIUM_PATH`、`PAGE_PLAYWRIGHT_MODULE`：使用已有Chromium和Playwright安装。
- `PAGE_VIEWPORT`：按视口宽度筛选，例如390或`1920,1440,1024`；2560同时覆盖1440与1119两种高度。可分组运行以缩短单个进程时长。
- `PAGE_PATH`：仅检查指定模块，例如`/high-throughput-workflow-demo`；多个路径用逗号分隔。
- `PAGE_STAGES=false`：跳过高通量完整阶段推进，用于断点定位复测。

默认检查15页×12档视口，包括899／900／901px及2K宽高边界；验证首屏、真实可滚动区域、字号与主题、主工作面圆角及阴影、外层溢出、主要标签、数据库五类子页面、单次／批量聚合和S0–S6。每项坐标误差不得超过1px。滚动探针逐个检查模块根节点、祖先和正文容器，并在检查后恢复位置；14页不允许标题移动，单体正向聚合必须实际发生整页滚动且标题位移等于负滚动距离。报告记录各容器的实际滚动量和标题位移，不能将无可滚动内容当作滚动成功样例。

每档视口完成后即保存JSON检查点，失败详情即时输出。单体正向聚合加载服务能力时会引入批量表单的上层组件，脚本分别检查初始和服务就绪后的标题，再对最终挂载的根节点执行滚动，避免读取已卸载节点。

知识检索按本地／在线／PDF往返切换，核对当前内容与选中标签匹配、非活动面板不绘制且不可交互；MD／DFT任务夹具覆盖排队、运行、取消中、完成、失败和已取消的公共文字、背景、边框及字体。截图文件名包含宽度和高度，区分原生2K与仅宽度达到2K的情况。

`test:pages:focus`覆盖390／1440视口、正常／减少动态效果、空／两候选结果共8个组合，检查结构反推抽屉初始焦点、Tab循环、关闭恢复、重开、快速关闭和打开中切页取消。它支持`DRAWER_BASE_URL`、`DRAWER_CHROMIUM_PATH`、`DRAWER_PLAYWRIGHT_MODULE`、`DRAWER_ARTIFACT_DIR`，所有计算响应均由本地夹具提供。

`test:pages:states`覆盖390／1920／2560视口的高通量S1错误CSV、错误区聚焦、样例加载和成功恢复，验证实际文字、背景、边框及数据表显示；使用上述`PAGE_*`环境变量。错误CSV仅在浏览器内验证，不上传到后端。
