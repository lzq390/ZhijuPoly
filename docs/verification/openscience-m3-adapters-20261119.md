# OpenScience M3 开发适配器双账号验收

本轮在独立开发环境 `dev-m1` 复用了 `test-user-a`、`test-user-b`、M1 私有卷和 M2 网页登录。PolyTAO 与单体逆合成分别使用独立的 MCP 进程、Unix socket 和服务密钥。工作区的可信工具路由按原工具名将调用送到对应的 MCP 进程，原六项工具继续走 11 月派生的网关。原生 NexPoly 接口按照发起操作的登录设置用户上下文、任务所有者和用量归属。正式验收记录见[双账号浏览器及账本结果](openscience-m3-adapters-20261119.json)。[生产同版六工具的前序验收](openscience-m3-20261119.md)

## 确认、收据和限流

- 模型可打开、读取参数草稿及查看获准的任务。确认工具只供网页参数卡调用。路由先在当前工作区查找会话和已保存的准备工具结果，再把本次表单动作限定到该草稿、会话和修订号。
- 适配器在每个用户的私有 SQLite 日志中保存草稿及其发起登录。用户在另一台设备重新登录后可以查看自己的草稿，提交仍须原登录确认。原生提交授权再次比对准备该草稿的登录与调用记录。[适配器](../../backend/app/auth/openscience_m3_adapters.py) · [原生请求授权](../../backend/app/auth/openscience_adapter_scopes.py)
- 任务幂等键由用户、草稿和确认时的修订号生成。原生已接受请求而适配器尚未写入回执时，恢复操作按原键查询。再次确认同一版本复用原任务。模型和浏览器均不持有可直接提交原生任务的服务密钥。
- 正式验收将每个适配器的新增提交限制为每用户每 60 秒 1 次。计数跨同一用户的多个登录，按适配器独立保存。确认重试复用原准入记录。交互开发默认每分钟 20 次。开发权益策略给每个会员的两个相关月度额度池各设 50 次，已有开发任务及用量保留。

## 双向验收

正式验收共创建 4 个原生任务。PolyTAO 在 A、B 的 `generation` 额度池各扣 1 次，逆合成在两人的 `chemistry_small` 额度池各扣 1 次。四次回执丢失后均找回原任务，其他用户的用量增量为零。从 A 首次确认到 B 成功提交并复查 A 仍被限流，整组检查在 PolyTAO 上耗时 9.936 秒，在逆合成上耗时 6.225 秒，均处于同一个 60 秒限流窗口内。

| 场景 | PolyTAO 和逆合成分别执行的检查 |
|---|---|
| 草稿 | A、B 在同名但独立的会话各准备参数。本人可读取、修改，保存后修订号递增，另一用户的修订和参数保持原值。用旧修订确认，以及跨账号读取、编辑、取消或确认对方草稿均受拒。模型尝试确认时没有生成任务。 |
| 发起登录 | A 的第二个登录可读取 A 的草稿，在首次提交之前及回执恢复之后代为确认均被拒。本人从实际参数卡点击确认。 |
| 回执与重试 | 对每位用户，在原生接受任务之后、适配器记录回执之前丢弃第一次响应。再次确认恢复同一任务。再重复确认仍是同一任务，对话只保存一条提交收据。 |
| 结果与个人用量 | A、B 分别从对话读取自己的候选结果，按候选顺序与原生结果核对。用对方任务编号访问适配器和原生接口均被拒。两人各自的个人用量页面接口可查自己的任务。 |
| 按人限流 | A 已占用提交名额后，用 A 的第二个登录确认另一份完整草稿，收到 429。B 在同一窗口成功提交，随后立即复查 A 仍为 429。被限流的草稿没有任务、扣额或准入记录。 |
| 对账 | 将每份草稿、原登录和幂等键与适配器日志、原生任务、权益结算及任务用量关联。验证每个有效确认只生成一个任务和一次扣额。 |

## 计算与复测

对话使用确定性开发模型选择工具。PolyTAO 与 ReactionT5 使用本地模型权重在 CPU 上完成推理。启动时校验发布清单 `ad19a4f1…` 及两个模型目录中所有文件的 SHA-256。测试用小分子输入、少量候选覆盖任务、结果和计量链路；GPU 吞吐与候选的科研质量需单独评测。[原生开发计算入口](../../backend/app/auth/openscience_m3_adapter_native.py)

沿用前序 M3 的 M1 注册表、两个回收状态的私有卷、独立数据库、审定的网关镜像及 Node 22 / Chromium 环境。主机还须保留两个固定 MCP 镜像和完整模型发布目录。从仓库根目录执行以下命令，输出报告使用新的文件名。重复验收会产生新的开发任务及真实开发额度记录。

```bash
python3 scripts/openscience_m2_dev.py \
  --m3-gateway-image sha256:6b6257257ed4c31a879ad2f525c288fc423121aeef55340da0825174a2338d1f \
  --m3-adapters --verify .runtime/openscience-m3-adapters/replay-01.json
```

启动器使用回环浏览器入口及无外网的开发容器。验证结束后回收两个实例，保留原私有卷、适配器日志和开发库。生产 9011 未参与本轮操作。
