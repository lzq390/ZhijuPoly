# OpenScience M4 开发模型与私有知识服务验收

本轮复用 `dev-m1` 的两个 NexPoly 测试账号、11 月工作区镜像、原 UID 和原私有卷。浏览器从平台登录进入各自的 OpenScience。模型用量和私有知识表保存在这套部署专用的 PostgreSQL，推理进程另存仅含请求 ID 和 token 数的回执。生产 9011 及其数据未参与操作。[浏览器及对账结果](openscience-m4-20261119.json)

## 模型用量

A 用 Chat Completions，B 用 Responses。两人在独立对话里各发一条不同的问题，浏览器检查了实际保存的非空回答。对账以发起登录、工作区会话、用户消息和单次模型请求 ID 为单位，包含同一轮的辅助请求。每笔已结算记录逐一比对本人的用量接口、PostgreSQL 账本和模型工作进程的原始回执。[浏览器验收](../../scripts/ci/verify_openscience_m4.mjs) · [独立对账](../../scripts/ci/openscience_m4_ledger.py)

正式窗口共有 4 笔实际结算，四份推理回执与个人账本逐笔一致。下表的输入包括 OpenScience 上下文和辅助调用。

| 账号 | 主对话协议 | 模型请求数 | 实际输入 token | 实际输出 token | 对方用量可见笔数 |
|---|---|---:|---:|---:|---:|
| A | Chat Completions | 2 | 10,171 | 24 | 0 |
| B | Responses | 2 | 10,189 | 24 | 0 |

模型为本机只读的 Qwen2.5-7B，使用 4 核 CPU 及 BF16 在无外网容器中推理。启动时验证固定发布清单 `2cdb0c3a…` 和清单内的权重、分词器、配置及索引文件。开发模型采用文本输入，单请求上下文上限为 16,384 token，最多生成 12 token。真实模型服务按分词器输入和实际生成的 token ID 数回执。本轮测量覆盖本地调用归属，外部商业供应商的出口、账单金额和吞吐仍待相应环境验证。[工作进程](../../backend/app/auth/openscience_m4_provider.py)

工作区模型调用须同时经过本人实例的私有 Unix socket、当前工作区代次及已登录页面授权的对话轮次。路由将模型与知识服务的凭据分开保存。网关对每个用户按 UTC 日期预留输入和最大输出，开发默认预算为每日 131,072 token，同时允许每人 2 条、全局 3 条模型流。断流、超时、缺少用量将产生单列的估算记录，迟到的工作进程回执可按原请求恢复真实计量。[服务鉴权](../../backend/app/auth/openscience_m4_dev.py) · [模型网关与账本](../../backend/app/auth/openscience_m4_model.py)

AC-14 另使用临时 PostgreSQL 与可控推理端验证故障时序。A 两条请求占用其在途额度后，A 的额外请求收到 429，B 仍能获得第三个名额并正常完成。日预算已被使用或预留时拒绝新增。用例覆盖两个协议、上游缺少 usage、上游异常、下游读到第一段后断开，以及重复提交结算和迟到真实回执覆盖估算。故障用例把实际和估算分别核账。[预算及断流回归](../../backend/tests/test_openscience_m4_model.py)

## 文档、检索和引用

| 操作 | 两个账号分别验证的结果 |
|---|---|
| 入库 | A、B 在知识库管理面板分别创建同名库，再上传同名、正文不同的 UTF-8 文件。每份文档在本人的库内产生一个可检索片段。 |
| 检索 | 两份文档共享一个检索词。网页和只读 MCP 都只命中本人的文档，搜对方正文独有的词均为零命中。显式混用本人和对方的库被拒绝。 |
| 引用 | 知识面板打开原文后，显示的片段与网页检索、MCP 检索和数据库中的片段一致。浏览器另核对了原文件下载。用对方的文档、下载及引用地址均返回 404，经 MCP 读取对方引用返回 `not_found`。 |
| 归属 | 知识库、文档、片段三张表均强制执行 PostgreSQL 行级权限。按记录核对所有者、正文摘要和引用摘要；两个账号以外的文档和模型用量增量为零。 |

开发服务支持 256 KiB 以内的 UTF-8 `.txt` 和 `.md`。检索使用 PostgreSQL 全文索引，并支持字面子串匹配。网页与 MCP 共用检索和引文读取逻辑。此次开发扩展只开放本人私有文档，批准的共享知识集名单为空。原服务的共享账户、存量文档与外部向量服务均未接入。这里验证的是检索服务返回且能回读原文的引用，模型自然语言答案的科研准确性另行评测。[私有知识服务](../../backend/app/auth/openscience_m4_knowledge.py) · [行级权限迁移](../../backend/migrations/openscience-dev/0007_m4_knowledge.sql)
