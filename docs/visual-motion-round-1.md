# 视觉交互优化：串行模块切换与手动验收

更新日期：2026-09-09。交付入口：当前开发环境 **9001**；没有发布或重启生产环境。

## 当前效果

主模块采用 **400ms 完全淡出 → 200ms 空白 → 400ms 完全淡入**。在串行切换版本基础上，两段动画各从 500ms 缩短到 400ms；空白和其他交互规则不变。

| 阶段 | 画面 | 路由与交互 |
| --- | --- | --- |
| 离开检查 | 旧页面保持可见 | 共用原有结构同步；`false` 阻止，异常、拒绝及 1500ms 超时沿用放行规则 |
| 退出 400ms | 旧内容 opacity 1 → 0 | 保留旧路由、旧页面；内容区停止鼠标和键盘交互 |
| 空白 200ms | 只见现有工作区背景 | 完全透明后提交目标 URL、参数和模块；正常挂载新页面，透明起始帧建立后计时 |
| 进入 400ms | 新内容 opacity 0 → 1 | 不等待 API、iframe 或 3D 全部加载；进入完成后恢复内容交互与焦点 |

两段曲线都是 `ease-in-out`，只改变内容节点的透明度；侧栏和平台顶部栏不随之淡出。没有平移、缩放、模糊、白色覆盖层、中央旋转图标或虚构的加载进度。

名义总时长为 1 秒，不包括离开检查、DOM 初始化、建立起始帧与浏览器调度。200ms 是明确的空白计时，不是接口等待门槛；复杂模块首次初始化阻塞主线程时，实际空白可能更长。慢请求继续显示模块原有加载或错误状态。

首次打开平台、同模块内分页/标签/参数变化、任务 ID 更新及数据轮询不播放主模块切换。旧版 1 秒、0.70 → 1 的单向淡入和标题上浮/错峰实验已停用并清理；页内和控件动效维持原规格。

## 统一动效参数

CSS 主来源：[motion.css](/data/lzq/gith/nexpoly-dev/frontend/src/styles/motion.css)。JS 读取必要计算样式，集中兜底见 [motion.ts](/data/lzq/gith/nexpoly-dev/frontend/src/lib/motion.ts)。没有新增运行时动画库。

| 场景 | CSS token | 规格 |
| --- | --- | --- |
| 主模块退出 | `--np-motion-module-exit` | 400ms，opacity → 0 |
| 主模块空白 | `--np-motion-module-gap` | 200ms，显式 opacity: 0 |
| 主模块进入 | `--np-motion-module-enter` | 400ms，opacity 0 → 1 |
| 主模块曲线 | `--np-ease-module` | ease-in-out |
| 控件颜色/边框/聚焦 | `--np-motion-control` | 120ms，位置与尺寸稳定 |
| 页内内容 | `--np-motion-tab` | 120ms，opacity 0.88 → 1 |
| 菜单与参数浮层 | `--np-motion-enter / exit` | 160 / 120ms，4px |
| 抽屉与移动导航 | `--np-motion-drawer-enter / drawer-exit` | 200 / 160ms，12px |
| 遮罩 | `--np-motion-backdrop` | 140ms |
| 2D/3D 翻转 | `--np-motion-flip` | 260ms |
| 导航说明延迟 | `--np-motion-feedback-delay` | 120ms，不代表结构已保存 |
| 拖宽 | 无尺寸过渡 | rAF 合并，每帧至多提交一次，松手提交最终坐标 |

其他进入曲线仍为 `cubic-bezier(0.22, 1, 0.36, 1)`，退出为 `cubic-bezier(0.4, 0, 1, 1)`。

## 实现与边界

### 单一导航事务

[App.tsx](/data/lzq/gith/nexpoly-dev/frontend/src/App.tsx) 使用 [useModuleTransition](/data/lzq/gith/nexpoly-dev/frontend/src/hooks/useModuleTransition.ts) 统一侧栏、模块内部跨模块入口、命令和浏览器前进/后退。请求携带目标 ID、名称、完整 URL、知识检索条件、任务 ID、数据集和 history 方式，在透明提交点一起生效。

内部阶段是 `idle / guarding / exiting / blank / entering`。递增事务标识、具体 Animation 实例和清理函数共同排除过期完成事件、定时器及异步守卫结果。WAAPI 完成事件为主，时长 + 80ms 的 watchdog 兜底；启动延迟不消耗正常 400ms 动画区间。空白用明确的 `opacity: 0` 保持，不依赖结束后残留的动画填充。

[AppShell](/data/lzq/gith/nexpoly-dev/frontend/src/components/AppShell.tsx) 只呈现阶段、等待提示、既有内容节点和焦点。视觉状态采用外壳订阅，阶段推进不要求 App 及全部业务页面重新渲染。没有第二份工作区、旧 children 快照缓存、路由 key 或新增滚动容器。

| 新操作发生时 | 处理 |
| --- | --- |
| 守卫或退出中 | 只换最终目标；共用一次守卫和退出，不重置退出时钟；中间目标不挂载、不写 history |
| 空白中 | 在透明状态检查当前模块，提交最新目标并重新计时 200ms；不再播放透明页面的退出 |
| 进入中 | 取消淡入，保留当前透明度；检查通过后从该透明度淡出 400ms；拒绝则恢复当前页面可见 |
| 重复点击当前待切换目标 | 不重播、不重置动画 |
| 未提交前点击原模块 | 取消目标并恢复原页，不新增相同 URL 的历史条目 |
| 空白中覆盖刚提交的站内目标 | 替换本轮尚未显示的 history 条目；已开始显示的页面保留记录 |
| 空白中更新当前模块的任务/检索 URL | 替换尚未显示的条目，不多留一条无参数历史；页面开始显示后恢复原有 history 规则 |
| 前进/后退 | 使用浏览器已经更新的最新 URL 快照，不额外 push；旧页面迟到的任务 URL 更新不得覆盖该快照 |
| 新建项目/会话等命令 | 不进入目标替换队列；通过守卫后，在提交点执行一次；保留显式重载 Home iframe 的原命令语义 |

目标行立即标记为待切换，120ms 后出现短说明，直到最终完成才清除；当前高亮随路由提交更新。空白中已提交的模块可能已经初始化，不能承诺所有中间目标“从未挂载”。

### 焦点、浮层与降级

- 从退出开始到进入完成，内容区 `inert` 且对辅助技术隐藏；需要移走旧内容焦点时，先聚焦稳定的主区锚点，使用 `preventScroll`。
- 详情抽屉的模态监听同步识别模块退出，暂停抢焦点；模块所属的任务筛选 body Portal 在退出开始时关闭。侧栏项目菜单不被当成模块 Portal 清理。
- 移动端通过守卫后关闭导航并开始内容退出。遮罩在自身退场完成前继续阻挡点击；若导航仍覆盖，内容不开始淡入。完成后聚焦主区；主动取消导航仍返回菜单按钮，恢复淡入不会稍后抢走焦点。
- 运行中开启减少动态效果或标签页进入后台：取消视觉动画和空白等待，直接提交已获准目标并恢复可见。未完成的业务守卫继续有效；卸载只清理，不再提交导航。
- 内容容器由 WAAPI 独占透明度；减少动态效果时显式禁用其 CSS transition，避免旧全局 0.01ms 样式制造残留的一帧。
- 动画失败、意外取消或结束事件丢失都能清理透明度和交互锁。真实请求失败仍由模块原反馈处理。
- 选择当前模块或在提交前点回原模块，也会收起移动导航，但不重播模块动画。开发热更新重新连接 effect 时，恢复清理后保留的 DOM，不重放已取消的导航。

### 保留的首轮优化与业务规则

通用/知识抽屉、移动导航、菜单和参数浮层仍使用 `useMotionPresence` 完整进入和退出；子元素事件不算面板完成，退出中重开会废弃旧回调。桌面并排抽屉在退出期间保留槽位、位置与间距。

`useDrawerResize` 保留 rAF 合并、最终指针坐标提交、失焦/取消/卸载清理、宽度边界、键盘调整和 2K 规则。拖宽期间不做尺寸追赶动画。`useFlipMotion` 保持 260ms 视觉完成锁，数据准备和结构校验仍独立管理。

共享画板所有权、原有条件挂载和保活规则不变；不因动画额外克隆或重建 iframe。知识检索往返的同一画板节点保留，其他原本需要所有权切换而重建的情况仍遵循原逻辑。

没有改造用户隔离、状态保存/恢复、API 或任务生命周期，也不修改外部站点及 iframe 内部路由。Demo 仍从原挂载时点运行既有等待、进度和阶段推进，不被视觉阶段暂停、重置或加速。高通量满高、工具栏和内部滚动的现有改动保留；本轮没有编辑这些业务文件，也不将其他任务的高通量改动混入动效提交。

## 手动验证清单

先妥善处理当前未提交输入，再刷新 **9001 页面一次**，以排除旧热更新状态；不需要重启服务。正常动效验收时，请关闭系统或 DevTools 中的“减少动态效果”。每次普通切换间隔约两秒，先看完整过程，再做快速点击。

| 检查 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 完整退出再进入 | 左侧“结构工作台 → 知识检索 → 数据库筛选”逐个切换 | 旧内容消失，背景明显停留，再出现新内容；侧栏和顶部不闪、不移动 |
| 提交时点 | 观察地址栏和当前导航高亮 | 旧页淡出时仍指向旧模块；完全透明后才提交新目标，而不是点击瞬间替换 |
| 快速换目标 | 旧页正在消失时连续点三个不同模块 | 最终只进入最后目标，不依次闪出三个页面 |
| 空白中再选 | 背景空白时再点另一个模块 | 不可见状态下改目标，重新短暂停留，然后完整从透明开始出现 |
| 淡入中再选 | 新页面出现到一半时点其他模块 | 从当前明暗程度退出；下一页仍从完全透明开始，不越来越接近直接出现 |
| 撤销和重复 | 退出前重复点目标，或点回原模块 | 重复不重置；点回原模块恢复原页，不增加同 URL 历史条目 |
| 内容不可误触 | 退出、空白、进入时点内容按钮或按 Tab | 不触发业务操作，也不能进入隐藏控件；完成后控件恢复，侧栏始终可选目标 |
| 页面内正常更新 | 当前模块内切标签、分页或修改参数 | 没有整页 1 秒动画；原有局部反馈正常 |
| 历史记录 | 连续完整访问几个模块，再前进/后退 | 到达正确模块及任务/检索参数；快速后退以最新地址为准，无额外 push |
| 抽屉/浮层 | 打开详情或任务筛选菜单后切换模块 | 没有悬空菜单、残留遮罩或详情抽屉抢回焦点；回来仍按原状态规则显示 |
| 移动导航 | 窄屏打开导航，Tab/Shift+Tab/Escape；选择模块 | 导航模态退场后新页才进入；选择后焦点到主区，取消回菜单按钮；项目菜单先处理 Escape |
| 运行中降级 | 切换到一半时打开减少动态效果；再正常切换 | 立即呈现已获准目标，无透明页或永久锁；后续直接切换。关闭偏好后恢复完整动画 |
| 后台与慢请求 | 动画中切浏览器标签再回来；观察慢接口模块 | 回来页面可见可操作；超过 200ms 的接口继续显示原加载状态，不无限停在背景 |
| 高通量布局 | 进入高通量页面，滚动内部列表/面板 | 页面满高、工具栏稳定；内部滚动，不新增整页滚动条；Demo 推进仍按原逻辑 |

守卫拒绝、异常、超时、过期回调、命令重复执行等难以手动制造的场景由自动化测试覆盖；不建议为验收在真实服务创建任务或故意破坏结构。
